## 五、课后议课标准流程

### 5.1 基础五步（陈大伟体系）

```
观课教师白描现象 → 观课教师提问讨论 → 授课教师回应+反问
     → 观课教师回应反问+贡献方案 → 主持人整合形成建构
```

### 5.2 问课版增强（《问课》第7章）

在"观课教师提问讨论"环节，用**差异化发问**替换笼统评价：

```
观课者白描现象（出示思维五证据记录）
   → 差异化发问（场景→精准→适配→主体→建设性）
   → 授课教师回应与反问
   → 共同归因（避开外归因与浅表化归因）
   → 生成"假如我来教"方案（问题+1：每个诊断必配对策）
   → 主持人提炼成果（教研成果提炼表四维度）
```

**发问纪律**：
- 证据前置：「我注意到……（可观察事实），我想了解……（问题）」
- 单问原则：每次只提一个问题
- 问题+1：每个诊断性问题必须紧跟一个"我们可以怎么做"

> 📋 完整的六类型发问句式库与自查表见 `differentiated_inquiry.md`。

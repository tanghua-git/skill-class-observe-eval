## 课前会议记录要点

1. **授课教师观课说明**：教学背景 → 教学创新点 → 重点观察方向
2. **观课方向分解框架**：目标-手段-效果 / 原有基础-学习目标-教学手段-教学效果 / 理性思考-实践活动-实践效果

## 课后议课标准流程（5步）

```
观课教师白描现象 → 观课教师提问讨论 → 授课教师回应+反问
     → 观课教师回应反问+贡献方案 → 主持人整合形成建构
```

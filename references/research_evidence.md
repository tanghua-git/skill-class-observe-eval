## 一、AIED 人机协同教研模式（四阶闭环）

针对当前人机协同教研中普遍存在的"提问失焦"与"协同失衡"双重困境，AIED 模式提供四阶行动框架：

| 阶段 | 名称 | 要解决的问题 |
|------|------|--------------|
| **A** | 定位教研目标（Aim） | 教研问题是什么？如何从模糊直觉转化为可讨论、可改进的真问题？ |
| **I** | 解读课堂现象（Interpret） | 课堂现象背后究竟发生了什么？先问清楚、问透彻，再谈改进 |
| **E** | 探究多源证据（Explore） | 有哪些证据能验证或修正我的初步判断？ |
| **D** | 萃取实践智慧（Derive） | 如何把零散认识转化为可用的实践经验？ |

> ⚠️ **顺序纪律**：为什么必须先完成"现象解释"，再进入"改进建议"？——顺序颠倒会导致**议题漂移**与**证据与问题脱节**。

### 1.1 定位教研目标（A）：从模糊直觉到精准问题

| 模糊直觉 | 自我校准与提问方向 | 转化后的精准教研问题 |
|----------|-------------------|---------------------|
| 这节课学生参与度不高 | 聚焦"学"的状态：是全体还是部分学生？发生在哪个环节？表现形式是什么（沉默、机械应答、游离）？ | 在小组合作论证环节，为何超过一半的小组仅停留在轮流发言，未能形成深度讨论与观点整合？ |
| 这个概念讲了好几遍，学生还是不懂 | 审视"教"的策略：讲授方式是否脱离了学生的前概念？是否缺乏从具体到抽象的思维脚手架？ | 在讲解"摩擦力方向"时，如何设计有梯度的实例与提问，才能有效破除学生"摩擦力总是阻碍运动"的前概念误区？ |
| 我感觉自己讲得很累，但效果不好 | 判断课堂的效能类型：是否陷入"低效教"（满堂灌）或"低效学"（学生失焦）？ | 在新公式推导的教学段落，如何将连续的教师讲授，拆解为几个关键的学生探究任务，以变"听讲"为"思考"？ |

### 1.2 解读课堂现象（I）：厚薄问课

借鉴"厚薄读书法"，穿透表象，洞察教学行为背后的设计逻辑与学生认知规律。

**「把课问薄」——做减法、追本质**（追问链：现象 → 细节 → 证据 → 意义 → 本质）

| 追问层 | 追问内容 |
|--------|----------|
| 现象 | 这个片段发生了什么？ |
| 细节 | 哪个细节最关键？好或不好在哪里？ |
| 证据 | 有什么证据链条支持这一判断？ |
| 意义 | 为什么会产生这个效果？反映了什么教学原理或策略问题？ |
| 本质 | 从这个片段中能提炼出什么关于教学的关键认识？ |

> **示例**：观察到"教师连续提出三个问题，但学生回答都很简短" → 细节：三个问题都是事实性回忆，缺乏递进性 → 证据：学生回答后即陷入沉默，随堂练习中涉及应用的问题错误率较高 → 意义：问题链设计未能激发深层思维，停留在知识再现层面 → **本质：教师对提问功能的理解偏向于检查记忆，而非促进思考，缺乏设计高阶问题的意识**。

**「把课问厚」——做加法、拓视野**（思维线索：归因 → 差距 → 价值 → 循证 → 预判）

| 追问层 | 追问内容 |
|--------|----------|
| 归因 | 该教学策略在什么条件下可能失效？为什么会失效？ |
| 差距 | 哪方面可以改进？可以从哪个细节入手？ |
| 价值 | 为何要改进？价值何在？ |
| 循证 | 改进依据是什么？有哪些证据支持？ |
| 预判 | 改进后将发生什么？可能出现哪些新的课堂现象？ |

### 1.3 探究多源证据（E）：三类证据源

| 证据来源 | 具体内容 | 对教研的价值 |
|----------|----------|--------------|
| **同伴证据** | 同学科组教师对同一现象的不同观察与解读 | 打破个人认知茧房，提供多元视角，避免主观偏颇 |
| **文献证据** | 相关的教育理论、教学法著作、学科教学实证研究论文 | 提供理论框架与原理支持，将个体经验上升到规律认识 |
| **案例证据** | 国内外优秀的同课例、名师教学视频片段、经典教学设计 | 提供可借鉴、可迁移的策略与操作方法 |

> 证据搜寻应有明确针对性，服务于解答当前核心问题。**教师应有意识地查找与自己初步判断相反的观点或案例。**

### 1.4 生成智慧（D）：教研成果提炼

单次教研的总结中，应有意识地进行成果提炼，将零散认识转化为可用的实践经验。

| 提炼维度 | 关键追问 | 示例 |
|----------|----------|------|
| **关键新认识** | 关于某个教学策略或学生认知规律，我们达成了什么新理解？ | 问题链设计需要从识记层面向分析、应用层面递进 |
| **核心证据与启示** | 哪些内部或外部证据最具说服力？给了我们什么启发？ | 学生随堂练习错误率数据提示概念建构环节存在断层 |
| **可操作的改进点** | 基于讨论，课堂上可以立即尝试的 1~2 个具体改变是什么？ | 在提问设计中，确保每个知识块后至少包含一个要求学生"解释原因"或"举例说明"的问题 |
| **新生成的概念/工具** | 是否将某种模糊的"好感觉"提炼成了明确的策略或分析工具？ | 将"课堂要有节奏感"具体化为"张弛度调控三步骤" |

> **螺旋上升闭环**：实践 → 问课 → 优化 → 再实践。建立个人的"教学实践智慧库"（电子笔记、思维导图），将每次教研的结晶分门别类归档。点状的"珍珠"将串成链，编织成个人独特的专业能力网络。

## 二、四类证据源与三角互证

### 2.1 外部教研证据的三类组成

| 外部教研证据 | 组成要素 | 教师可以怎么做 |
|--------------|----------|----------------|
| **衍生多模态数据** | 课堂交互数据、师生言语文本、学生作业与作品数字化档案 | 用手机录音常态课，转成文字分析提问类型；每周收集 3~5 份典型作业拍照存档，标注思维痕迹 |
| **同类课例对比数据** | 教学设计方案库、课堂教学实录视频、教学反思与同行评议文本 | 在国家中小学智慧教育平台下载 3 份同课题名师教案，对比目标设定差异 |
| **教育理论与实验数据** | 经典教育理论、前沿学术研究成果、政策文件与报告、前测后测对比数据、量表测评数据、过程性跟踪数据 | 在知网检索"课堂提问+布鲁姆认知目标"相关实证研究；查阅课标中核心素养表述；实施新策略前后做对比测试 |

**衍生多模态数据的三种形态**：

| 数据形态 | 数据来源 | 核心功能 |
|----------|----------|----------|
| 课堂交互数据 | 智慧课堂系统自动记录 | 直观呈现课堂节奏与学生参与状态 |
| 师生言语文本 | 课堂录音逐字转写 | 评估师生对话的思维深度（提问认知层级分布） |
| 学生作业/作品数字化档案 | 学生日常学习成果采集 | 洞察学生思维发展的路径与特征 |

**实验型证据的三种类型**：

| 数据类型 | 采集方式 | 分析指标 |
|----------|----------|----------|
| 前测与后测对比数据 | 策略实施前后用相同或等值测试题检测 | 平均分、及格率、各分数段分布的变化 |
| 标准化量表测评数据 | 借助信效度较高的量表测量 | 学习兴趣、批判性思维、合作能力等维度得分 |
| 过程性跟踪数据 | 较长周期内持续记录学生的学习行为 | 登录频率、视频观看次数、讨论区发言质量等 |

### 2.2 获取与应用外部证据的四个步骤

| 步骤 | 关键动作 | 自检 |
|------|----------|------|
| 1 明确证据需求 | 从教学实际困惑出发，把模糊感受转化为具体研究问题 | 问题是否具体到"某个学科、某个学段、某个教学环节"？是否明确了需要哪一类证据？ |
| 2 多渠道采集证据 | "向上"取经（平台/数据库）、"向外"借力（区域/校际）、"向内"挖掘（本校教学痕迹） | 三类证据（向上/向外/向内）是否形成相互补充？ |
| 3 解读证据内涵 | 定量与定性结合；比较鉴别与归纳提炼；探究矛盾原因 | 是否同时使用定量数据与定性资料？不同来源证据是否指向相同结论？ |
| 4 教学实践验证 | 设计改进方案 → 实施与观察 → 评估与反思 | 改进方案是否具体到"下一节课、哪个环节、改变哪个行为"？ |

### 2.3 三角互证（增强结论可靠性的关键方法）

一个结论若得到三个方向的支撑，其可靠性显著提升：

| 支撑方向 | 说明 |
|----------|------|
| 理论依据 | 有经典学习理论作为支撑 |
| 外部数据 | 在多篇学术实验报告中显示积极效果 |
| 实践成效 | 在本校尝试时观察到学生参与度提升 |

> 评课用法：报告中给出改进建议时，如能同时指出"这个建议有理论基础 + 有同类案例佐证 + 符合本课观察到的现象"，说服力远高于单凭经验。

### 2.4 引入外部证据的三大误区

| 误区 | 表现 | 应对策略 |
|------|------|----------|
| **证据堆砌** | 只求数量不求质量，收集大量名师教案、实验报告、数据图表，却未聚焦核心环节 | 建立"问题锚点"（一句话写清要解决什么问题）；遵循"少而精"（精选 3~5 份最直接相关的证据）；使用证据矩阵表（按"问题指向—证据类型—重要发现—可用策略"整理） |
| **情境依存** | 外部证据中效果显著的策略，直接移植到自己的课堂却大打折扣 | 溯源情境（先了解证据产生的原始条件）；适配改造（哪些可直接用/需调整/暂不具备条件）；小步试点（先个别班级试行，收集反馈再推广）；持续追踪 |
| **实践闭环缺失** | 得出"小组合作需要明确角色分工"的结论，却没在下一节课设计角色卡并观察效果 | 方案具体化（转化为"下一节课、哪个环节、改变哪个行为"）；实施即收集（同步收集过程性与结果性数据）；前后对比；形成新问题（作为下一轮教研起点） |

## 三、教研理论的使用规范

### 3.1 常用经典教研理论

| 理论 | 简明阐述 | 适用教研主题 |
|------|----------|--------------|
| 最近发展区理论 | 学生今天在他人帮助下能做的事，明天就能自己做 | 同课异构观察设计；师徒结对听评课 |
| 掌握学习理论 | 只要给足时间、给对方法，90% 的学生都能学会 | 学困生集中补漏策略；单元测验讲评设计 |
| 认知负荷理论 | 工作记忆一次只能处理少量信息，把复杂任务拆小，别让学生认知过载 | 数字教学资源设计与优化；复习课知识图谱设计 |
| 先行组织者理论 | 讲新知识前，先给旧知识、生活经验搭框架 | 新旧知识衔接困难；单元起始课导入设计 |
| 做中学理论 | 听会忘，看能记，做才懂 | 科学课观察实验设计；数学概念课教具开发 |
| 自我决定理论 | 人有三种与生俱来的心理需求：自主感、胜任感、归属感 | 学困生习得性无助干预；小组合作学习动力不足诊断 |
| 布鲁姆认知目标分类理论 | 认知从低到高分六层：记忆、理解、应用、分析、综合、评价 | 课堂提问层次诊断与改进；试卷命题双向细目表设计 |
| 元认知理论 | 对自己思考过程的觉察与调控 | 错题订正深度化研究；学生自我反思能力培养 |

### 3.2 教研问题—理论匹配速查表

| 教研类型 | 遇到的教研问题/场景 | 可切入的理论或框架 | 应用提示 |
|----------|---------------------|--------------------|----------|
| 观课、评课类——评不明白、评不专业 | 听课、评课缺乏共同标准，各说各话 | 课堂观察 LICC 范式 | 从四维度（学生学习、教师教学、课程性质、课堂文化）进行观课、评课 |
| | 课例研讨停留在"好/不好"层面，说不清为什么 | **问课 WISE 课堂分析理论** | 锁定课堂转折点，用理论解释亮点或卡点 |
| 课程设计类——想创新、没框架 | 教研组想做跨学科主题学习，缺少设计思路 | C-POTE 模型 | 先圈一个真实问题，再倒推需要用到哪些学科工具 |
| | 校本课程开发缺乏系统框架 | 逆向教学设计理论 | 先问学完这门课学生能带走什么，再去想评价任务和活动安排 |
| 课题论文类——想研究、没套路 | 课题申报书中"核心概念"难以界定 | 系统性理论 | 一问起源，二问内涵，三问边界，四问作用 |
| | 教研活动长期低水平重复，找不到突破点 | 行动研究 | 计划—行动—观察—反思，下一轮带着新认识再走一圈 |
| 学情诊断类——看得出、找不准病根 | 学生上课不举手、小组讨论不叽声 | 自我决定理论 | 诊断课堂是否缺乏自主感、胜任感、归属感，缺哪个补哪个 |
| | 错题订正就是抄答案，下次照样错 | 元认知理论 | 把订正改成复盘：当时是怎么想的？卡在哪一步？ |

### 3.3 教研理论使用错位（五种，禁区 ❌12 的判据）

| 错位类型 | 曾经这样用 | 原因 | 如何转化 |
|----------|------------|------|----------|
| **大理论套小问题** | 用建构主义解释学生忘带作业 | 理论层级过高，解释力泛化 | 换成习惯养成、执行功能等中观概念 |
| **标签式使用** | 评课时说这节课体现了多元智能，但说不清体现在哪 | 理论沦为话术，未进入教学设计 | 先明确用哪个智能通道设计了哪个环节 |
| **用反方向** | 用最近发展区论证分层作业就是让学困生少做题 | 只取"难度适配"，丢了"社会互动与支架" | 设计合作机制、提供解题支架、同桌互讲互评 |
| **倒果为因** | 学生没兴趣，就说因为缺乏内在动机 | 用术语重新描述现象，没真正解释 | 追问"为什么缺"——是太难？太重复？没选择权？还是师生关系问题？ |
| **理论垄断** | 所有问题都用同一理论解释 | 只熟悉一个理论，舍不得换 | 建立"理论组合拳"意识——一个主刀诊断，两个辅理论开方 |

### 3.4 教研理论准入自检表（引用任何理论前必过）

| 判断维度 | 自检问题 | 可用 | 慎用 |
|----------|----------|------|------|
| **匹配度** | 我的困惑/观察到的现象，是这个理论原本试图解释的问题吗？我能说清"这个理论凭什么能帮我看懂这件事"吗？ | 能说清二者的关联，而非生拉硬拽 | 只是觉得这个理论"有名""高级""别人在用" |
| **解释力** | 套用这个理论后，我对学生/课堂的看法发生了什么变化？它是否让我看到了之前没注意的东西？ | 发现了新角度，或把模糊的感觉说清楚了 | 只是给现象贴了个理论标签，没有新认知 |
| **可转化** | 基于理论，我能明确说出下一节课/下一次教研的做法吗？这个行动是我能直接执行的吗？ | 有具体、可落地的教学调整方向 | 停留于应该怎么做，却说不出具体如何做 |
| **时效度** | 这个理论被修正过吗？其他学者提出了更适用于当今课堂的公认理论吗？ | 知道理论的前世今生和适用范围 | 拿原典硬套，忽视学界后续讨论 |
| **兼容度** | 理论之间打架吗？谁主谁次？ | 各理论锚定的问题清晰，执行时不冲突 | 堆砌术语，互相拆台 |

> **理论融合原则**：
> ① 别问"这节课用了什么理论"，问"这个现象还能怎么看"。
> ② 主理论管诊断，辅理论管开药方。
> ③ 融合不是掺在一起，是分工合作（如：前 10 分钟学生懵 → 认知负荷问题；中间 20 分钟不举手 → 自我决定问题；后 10 分钟练了还错 → 元认知没跟上）。

## 四、求助教研同行（议课组织方案第四节来源）

### 4.1 教研共同体的四类角色

| 角色 | 核心功能 | 能帮什么 |
|------|----------|----------|
| **理论专家** | 协助界定教研问题的概念；讲解课堂设计的学习理论；引导教师生成研究性理解 | 帮教师"想得更深"——为实践经验建立学术参照 |
| **教研专家** | 设计行动研究等研究工具；结合量化与质性数据；批判性检验研究结论 | 帮教师"证得更稳"——确保研究过程的严谨性与结论可信度 |
| **科组带头人** | 可操作性评估教研成果；调和学科核心要求与创新实践；推动团队共识 | 帮教师"看得更准"——确保不偏离学科核心概念与思维方式 |
| **学科同侪** | 课例分析与同课异构讨论；小组备课与资源共享；实践问题即时反馈 | 帮教师"做得更细"——提供具体操作层面的经验 |

> 四类角色相互支撑：**理论提供方向、方法保障严谨、学科确保定位、同侪优化细节。**

### 4.2 同行研判的三个阶段

**阶段一：研判前——明确议题与凝聚焦点**
准备一份清晰的"同行研判提案"：

| 类目 | 填写说明 | 示例 |
|------|----------|------|
| 研判议题 | 一句话说清核心问题 | 如何提高小组讨论中边缘学生的参与度？ |
| 议题类型 | 勾选最匹配的一项 | □研究假设验证 □实践难题解决 □创新方法评估 |
| 背景描述 | 简述教学设计、具体困境、困扰时长 | 五年级语文小组讨论中，总是几个优等生主动发言，约 30% 的学生处于旁听或走神状态 |
| 已收集的证据/资料 | 证据类型及获取方式 | 观察记录（2次课堂记录表）；视频片段（5分钟小组讨论）；学生访谈（3名沉默学生，各2分钟） |
| 已尝试的解决措施 | 说明做了什么努力，效果如何 | 尝试过给每组指定组长，但组长变成了"话事人"，其他人更不敢说了 |
| 最希望同行提供的帮助 | 提出具体需求 | 帮我分析视频中那个女生不参与的原因；大家有没有具体的"轮流发言"工具或策略可以分享？ |

**阶段二：研判中——结构对话深度研讨**
规则：研讨聚焦教学议题本身，而非评价教师个人；疑问最好附带可行建议；鼓励基于经验或知识提供依据。

流程：发起者陈述背景与困惑 → 与会者澄清性提问 → 分组或集体多维探讨 → 整合分析与风险提示 → 共同商讨后续步骤。

**阶段三：研判后——转化成果，持续跟进**
识别可直接采纳的观点；标注存在分歧或需更多数据验证的观点；留意需要规划或获取资源的中长期建议；制定具体行动计划；设计小规模尝试方案验证建议。

### 4.3 同行研判质量标准表

| 维度 | 核心标准 | 常见偏差 | 自检提示 |
|------|----------|----------|----------|
| 议题聚焦度 | 是否围绕"具体教学问题"展开？ | 话题发散，转为经验分享或价值判断 | 讨论结束时，是否还能清楚说出"我们解决的究竟是什么问题"？ |
| 问题诊断深度 | 是否触及问题成因？ | 停留在表层建议，如"多鼓励学生" | 是否追问过"为什么会这样"？是否区分了现象与原因？ |
| 多元视角参与度 | 是否呈现不同角色视角？ | 只有单一经验视角主导 | 是否出现至少 2~3 种不同分析路径？ |
| 证据意识 | 讨论是否基于数据或事实？ | 以主观印象代替证据 | 所提建议是否有依据？ |
| 行动生成度 | 是否形成可执行方案？ | 讨论热烈但无行动安排 | 会议结束时，是否形成具体行动清单？ |
| 跟进闭环性 | 是否安排后续验证？ | 讨论一次性结束 | 是否约定了"下一次回来汇报什么"？ |

## 五、人机协同共研（可选，用于议课组织方案）

### 5.1 四类角色智能体的构建要点

| 智能体角色 | 定位 | 核心能力 | 表达风格 |
|------------|------|----------|----------|
| **教学专家** | 拥有 30 年教龄的特级教师 | 快速诊断教学设计亮点与不足；提出"如果是我，会怎么设计"；关注环节逻辑递进 | 温和而专业；建议具体可操作，不说空话套话 |
| **学科专家** | 高校学科教学专家 | 判断知识性错误；指出知识点在学科图谱中的位置；提供学科前沿观点 | 严谨专业、有理有据；发现问题明确指出并给正确表述 |
| **学科教研员** | 经验丰富的教研员 | 对照课标评估目标设定与达成；分析时间分配、互动频次、提问层次；擅长组织评课语言 | 客观理性、语言简洁；先肯定亮点，再指出不足，最后给建议 |
| **听课教师** | 入职 3~5 年的青年教师 | 从年轻教师视角说出"如果是我，这里会怎么处理"；敏锐发现学生困惑点 | 亲切真诚，像邻桌同事；先说最喜欢的地方，再说困惑 |

### 5.2 听课评课场景的人机协同流程

| 教师做什么 | AI 做什么 | 成果 |
|------------|-----------|------|
| **准备课堂实录**：将课堂视频、录音整理成教学过程文字稿 | 等待接收任务 | 可供 AI 分析的课堂原始文本素材 |
| **发起多维评课**：将素材同时发给 2~3 个不同角色的智能体 | 教学专家分析教学逻辑、环节设计；教研员评估目标达成、师生互动；听课教师分享真实感受与学生视角 | 收获 2~3 份来自不同视角的评课意见 |
| **对照分析**：将多份评语放在一起对比，找出共识问题、分歧、盲点 | 任务完成，等待追问 | 形成改进的教学方案 |
| **追问深挖**：针对共识问题或感兴趣的分歧点追问细节 | 提出相关建议 | 可改进的细节方案 |
| **形成改进清单**：综合所有意见，结合班级实际，整理出"下节课可尝试的 3 条改进点" | 可暂不参与 | 一份可直接落地的课堂改进行动计划 |

**提示词模板（发给不同角色的智能体）**：
> 这是我［课堂主题名称］的课堂过程。请你以［角色名称］的身份回答。
> **亮点**：这节课最值得肯定的 1~2 个地方是什么？请结合具体片段说明。
> **问题**：这节课最大的 1~2 个改进点是什么？请指出发生在哪个环节。
> **建议**：如果只给一条"下节课就能试"的具体建议，你会说什么？

### 5.3 与智能体交流的五条纪律

1. 至少要问 2~3 个不同角色的意见（"三个臭皮匠才能顶个诸葛亮"）
2. 别盲从共识——即使三个智能体建议一致，也要自问"这真的适合我的学生吗"
3. 别忽略分歧——智能体观点不一致的地方往往藏着被忽略的真问题
4. 别不问细节——如果智能体只说"这里可以优化"，一定要追问"具体怎么改，能举个例子吗"
5. 别直接套用——智能体的建议要经过教师思考后方能调用

### 5.4 苏格拉底式提问设置（防止认知惰化）

在智能体角色构建的表达风格中，加入以下设置：

> 1. 不要直接给我答案或建议，而是通过层层追问，引导我自己找到解决方案。
> 2. 追问逻辑请遵循：先问"看到了什么"（引导我描述具体现象，而非主观判断）→ 又问"依据是什么"（引导我检查证据，而非凭感觉下结论）→ 再问"原因可能是什么"（引导我多角度归因，而非停留在表面）→ 最后问"可以尝试什么"（引导我自己生成策略，而非被动接受方案）。最终，如果我表达"真的想不出来"等类似想法，再给出建议。
> 3. 你的每一个问题，都应该是为了让我多想一步，而不是替我省掉这一步。

**四步引导**：陈述事实 → 检查证据 → 问题归因 → 策略生成。

### 5.5 教师反思交流发言规范语

| 发言类型 | 模糊话语 | 具体话语 |
|----------|----------|----------|
| 陈述事实（说现象） | 我觉得学生没听懂；这节课效果不太好 | 前排有学生皱眉头，后排两个学生在小声问同桌；提问环节我连问了 3 个学生，都没有答出来 |
| 检查证据（找依据） | 学生就是不认真听课；这个班基础太差了 | 第 3 题错误率达到 65%，主要集中在概念混淆上；发现自己在讲解关键点时，语速突然加快了 |
| 问题归因（挖设计） | 学生不爱举手；是我讲得不够生动 | 面对问题学生只需要回答对或不对；讲解难点时，只给了定义，没有联系生活情境 |
| 策略生成（想方案） | 你说我该怎么改？你给我更好的设计吧 | 如果改成"你支持哪种观点、理由是什么"，会不会让学生说得更多？将任务单第 2 题改为"先独立写思路，再小组交换看"，这样会不会让每个人都有思考的机会？ |

### 5.6 善用 AI（智能体）自检表

| 应用维度 | 自检问题 |
|----------|----------|
| 使用界限 | 是否让 AI 代替我完成了本应由我独立完成的核心创造性工作？ |
| | 是否在考试命题、作业批改、学生评价等敏感环节，不加甄别地采纳了 AI 的建议？ |
| 原创性维护 | 是否将 AI 生成的教学设计、反思报告，复制粘贴后当作自己的成果？ |
| 数据隐私 | 上传给 AI 的课堂实录、学生作业等信息，是否去除了学生的个人信息？ |
| 批判看待 | 对 AI 的建议，是否都自问过："它说得有道理吗？符合我的实际情况吗？" |
| 示范引领 | 是否向学生示范了如何正确、有道德地使用 AI？ |

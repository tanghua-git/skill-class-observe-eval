【硬规则】「课标原文」与「教研转化」必须分栏；凡教研转化句，不得回引为「课标规定／课标要求」。

## 四、L3 素养 → 课堂可观察表现

> 【教研转化层，非课标原文】把 L2 用词转译成**能看见**的课堂事实，属观察线索示例库，**不是达标线、不是课标要求**，不得写成「课标规定学生应……」。左列名称逐字取自 L2，右列全为教研转化。

### 4.1 数学（深描·义教「三会」）

| 素养维度（逐字） | 课堂上能看到什么 |
| --- | --- |
| 会用数学的眼光观察现实世界 | 在教室照片上圈出 3 处「一样长」的边，痕迹留在学习单；购物情境里先写「要问的是单价」再列式，提问被板书 |
| 会用数学的思维思考现实世界 | 比较异分母分数前先写「化成同分母」再动笔；被追问「人数换成 41 呢」时指着算式说「只改这一步」 |
| 会用数学的语言表达现实世界 | 把「每排 6 人、共 5 排」写成算式并旁注单位；汇报时说出带条件的整句结论，不只报数值 |

高中数学六维（表 B）**骨架版·待深化**，不得套用「三会」。

### 4.2 语文（深描·义教四维）

| 素养维度（逐字） | 课堂上能看到什么 |
| --- | --- |
| 文化自信 | 讨论习俗时举出家里 1 个做法并说「我们家一直这样」；朗读后在书页空白处写下与方言俗语相近的一句 |
| 语言运用 | 初稿 3 处重复词换成不同说法，改痕用另一色笔留在原稿；长段压成 2 句，人物、事件、结果未丢 |
| 思维能力 | 对结论提出「只说了白天，晚上呢」，便利贴贴到质疑区；两段间画因果箭头并说「因为这句，所以才有后面那句」 |
| 审美创造 | 仿写保留节奏、只换 2 个意象词，让同桌指出变化处；朗读时把某句读慢，被问答「这里要留一点空」 |

高中语文四维（表 B）**骨架版·待深化**，不得与义教四维混用。

### 4.3 物理（深描·四维度）

| 素养维度（逐字） | 课堂上能看到什么 |
| --- | --- |
| 物理观念 | 解释小车停下说「有力在拦着它」而非「力气用完了」，两句并列板书；把斜面、滑轮、弹簧归进「能量从一处到另一处」栏 |
| 科学思维 | 数据表里圈出 1 个偏离点并注「这一次数错了」，未删；把实物电路转画成符号图，逐个元件指认 |
| 科学探究 | 动手前写「只改一个：斜面角度」，其余器材未动；两次读数差别大时重测第三次，三次数据全留 |
| 科学态度与责任 | 结果与预期相反仍留原数据，旁注「和想的不一样」；发现同伴漏写单位，回看仪器面板后补上 |

物理表 A／B 四名相同但水平不同，不得混用（见第六章）。

### 4.4 信息科技（深描·四维度）

| 素养维度（逐字） | 课堂上能看到什么 |
| --- | --- |
| 信息意识 | 搜索前写「要近一年、带来源的数据」，关键词改成带限定词的一串；面对冲突信息点开页面看日期与发布方 |
| 计算思维 | 把「整理全班名单」拆成去重、排序、数人数 3 步清单；画出含两条分支箭头的流程图并指认 |

## 五、L4 覆盖审计规则

【教研转化层】依据《问课》2-4「一堂课难以覆盖学科核心素养的全部方面，素养的培育应遵循长期主义原则」（方法论文献观点，非课标原文），单课时采「聚焦＋留白」，禁全表打勾。

| 规则 | 内容 |
| --- | --- |
| R1 锁定 | 只从 L2 锁定 2-3 个重点素养，逐字抄录并写明理由 |
| R2 判定 | 逐项判「充分／部分／未见」，附时间点＋可见事实（原话、板演、作品） |
| R3 留白 | 其余标「本课未触及（长期主义）」，不得判未见／未达成，不计缺陷 |
| R4 禁贴标签 | 严禁对 L2 全表逐项评级，出现即判无效，退回 R1 |
| R5 分栏 | 判定与证据属教研转化层；条目出处按定位卡登记，收尾写「条目原文以课标纸质版为准」 |

口径（教研转化层）：充分＝2 条以上可复核事实；部分＝仅 1 条或含糊；未见＝确无事实且说明检索时段。

| 锁定素养（L2 逐字） | 判定 | 证据（时间＋事实） | 性质 |
| --- | --- | --- | --- |
| 待填 | 充分／部分／未见 | 待填 | 教研转化层 |
| 其余素养 | 本课未触及（长期主义） | 不作判定 | 教研转化层 |

【教研转化层｜只规定条目如何合法定位】

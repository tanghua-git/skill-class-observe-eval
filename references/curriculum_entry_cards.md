# 课标条目定位卡·标准写法与速查

> 内部参考文件：把「内容要求／学业要求条目」栏改为离线可稳定填写的完成态文字；不直接进入交付报告。

## 一、定位与修复说明

### 1.1 根因与字段重定义

旧版要求填「联网核验后的逐字原文」，失败即留未完成表述（该做法已废止）。实测：教育部官网课标 PDF 为扫描件、无文本层，数学课标 PDF 约 40 MB，Range 下载 8 MB 后 pdftotext 无文本层；ictr.edu.cn 版下载不完整。故该栏只能写「待核实……本次未取得可逐字复核的条目原文与编号……」，用户明确指出「是没有完成的，存在很大问题」。根因是字段依赖外部不可控资源，须换掉定义。

该栏由「逐字原文」重定义为「可离线稳定填写的三要素」：

| 要素 | 含义 | 对应模板行 | 离线依据 |
| --- | --- | --- | --- |
| 结构定位 | 领域／主题名与学段 | 对应学习主题 | 第四节速查表 |
| 教研化要点 | 教研语言概述两类要求，标注非原文 | 内容要求要点、学业要求要点 | 本课内容与观察事实 |
| 出处指引 | 版本、主题／学段，收尾句指向纸质版 | 条目出处 | 版本与学段信息 |

三要素均可离线写成完成态实句；逐字引用改在议课现场纸质版比对环节进行。

### 1.2 三条硬纪律

| 硬纪律 | 含义 |
| --- | --- |
| 不杜撰原文 | 严禁编造条目原文、编号、页码，严禁把解读、转述、专家观点冒充原文；概述句须带「（要点概述，非课标原文）」 |
| 不留未完成表述 | 每栏均为完成态实句，禁用「待核实」「本次未取得」「建议对照确认」及自陈失败的句子 |
| 不依赖联网 | 离线可填为设计目标；报告不交代下载、解析、核验过程 |

小节号是文档结构编号，非课标条目编号；课标条目编号一律不填。

## 二、【课标条目定位】标准写法

四行句式可直接照抄；尖括号「〈〉」为替换位，交付件不得保留尖括号或编写指引。

### 2.1 四行标准句式（完成态实句）

```
- 对应学习主题：本课归属于「〈领域〉—〈主题〉」主题，对应〈学段〉的学习内容。
- 内容要求要点：〈用教研语言概述本课对应的内容要求与关键学习活动〉。（要点概述，非课标原文）
- 学业要求要点：〈用教研语言概述学生可观察的学业表现〉。（要点概述，非课标原文）
- 条目出处：《〈学科〉课程标准（〈版本〉）》「〈主题〉」主题／〈学段〉；条目原文以《〈学科〉课程标准（〈版本〉）》纸质版为准。
```

四行均为完成态实句：确定归属、两句教研语言概述并逐句标注、出处以收尾句收束；2.2 即填妥范式。禁止填编号页码、把未回查结构名写成官方名称、仿写句式伪装原文。两类要求合并时须写明「内容要求与学业要求合并概述」并同样标注。

### 2.2 完整填写示例一：小学数学《鸡兔同笼》（第二学段·数量关系）

- 对应学习主题：本课归属「数与代数—数量关系」主题，对应第二学段（3–4 年级）。
- 内容要求要点：本课以「鸡兔同笼」为问题情境，引导学生用列表、假设与图示梳理头数与腿数的数量关系，在多解比较中体会模型化表达与有序思考。（要点概述，非课标原文）
- 学业要求要点：学生能说明每步算式的实际含义、检验结果是否符合题意，并把「假设—验证」迁移到结构相近的问题上。（要点概述，非课标原文）
- 条目出处：《义务教育数学课程标准（2022 年版）》「数与代数—数量关系」主题／第二学段；条目原文以《义务教育数学课程标准（2022 年版）》纸质版为准。

### 2.3 完整填写示例二：初中物理《牛顿第三定律》（8–9 年级·运动和相互作用）

- 对应学习主题：本课对应义务教育物理 8–9 年级「运动和相互作用」内容方向，聚焦物体间相互作用，属力学范畴。
- 内容要求要点：本课以物体间相互作用为观察对象，引导学生通过实验与实例辨析「作用与反作用」跟「一对平衡力」的差异，形成对力的相互性的整体认识。（要点概述，非课标原文）
- 学业要求要点：学生能举出生活实例说明一对相互作用力的大小、方向与作用对象关系，并用示意图解释常见现象而不与平衡力混同。（要点概述，非课标原文）
- 条目出处：《义务教育物理课程标准（2022 年版）》「运动和相互作用」内容方向／8–9 年级；条目原文以《义务教育物理课程标准（2022 年版）》纸质版为准。

> 内部说明（不写入交付报告）：物理主题未回查，速查表内标为结构名未回查，不冒充官方主题名。

### 2.4 完整填写示例三：小学语文第二学段精读课（文学阅读与创意表达）

- 对应学习主题：本课归属「发展型学习任务群—文学阅读与创意表达」，对应第二学段（3–4 年级）阅读与表达内容。
- 内容要求要点：本课以精读为主要方式，引导学生在整体感知基础上关注作品的语言与形象，通过朗读、批注与复述体会观察和表达的顺序，并说出阅读感受。（要点概述，非课标原文）
- 学业要求要点：学生能复述课文内容与表达顺序，结合具体词句说明喜欢的理由，并完成一段有观察依据的简短仿写。（要点概述，非课标原文）
- 条目出处：《义务教育语文课程标准（2022 年版）》「文学阅读与创意表达」学习任务群／第二学段；条目原文以《义务教育语文课程标准（2022 年版）》纸质版为准。


## 三、禁用表述清单

### 3.1 逐条禁用与替换写法

下列表述在交付报告中一律禁用，字面与同义改写（「尚待核对」等）同禁。

| 序号 | 禁用表述 | 统一替换写法 |
| --- | --- | --- |
| ① | 待核实 | 写第二节四行完成态实句 |
| ② | 本次未取得 | 删句，由两条要点行承担内容 |
| ③ | 扫描件 | 删载体描述，只留版本与收尾句 |
| ④ | 无可提取文本层 | 同上，不交代过程 |
| ⑤ | 建议对照课标原文确认 | 改为统一收尾句 |
| ⑥ | 置信度：低 | 整项删除，不设置信度栏 |
| ⑦ | 条目原文：待核实 | 整行替换为「条目出处：……」 |
| ⑧ | 按第七节三级流程 | 删内部指针，直接给结果 |
| ⑨ | 该条目的内容可能已经过时，建议更新并重新核验 | 整句删除，版本以出处行为准 |
| ⑩ | 已定位官网 PDF、Range 下载、pdftotext、下载不完整 | 全部删除，只留结论 |
| ⑪ | 【待核实：结构名未回查】 | 交付件不出现，改用「内容方向」等完成态表述 |

### 3.2 统一收尾句

课标依据、条目出处类文字末尾一律以固定句式收尾：**条目原文以《XX课程标准（2022 年版／2017 年版 2020 年修订）》纸质版为准**，XX 为学科名，版本按学段择一。

| 学段 | 统一收尾句（固定） |
| --- | --- |
| 义务教育 | 条目原文以《义务教育XX课程标准（2022 年版）》纸质版为准 |
| 普通高中 | 条目原文以《普通高中XX课程标准（2017 年版 2020 年修订）》纸质版为准 |

该句为完成态结论，不附带「建议」「确认」「更新」类动作；「条目原文以课标纸质版为准」为简写，交付时展开为完整式。

## 五、报告表达纪律

本文件供模型内部使用。交付报告不得出现：参考文件名（含本文件名）、内部编号（L1–L4、§、表 A、①–⑧）、「课标原文层」「已核验清单层」「课标解读层」「教研转化层」等层级标签，以及编写指引句（如「请按模板替换」）。内部指针一律改写为自然语言。

| 内部指针（禁止出现在交付件） | 交付件中的自然语言写法 |
| --- | --- |
| curriculum_entry_cards.md 第四节 | 课标条目定位速查 |
| curriculum_literacy_map.md L2 | 课标核心素养 |
| discipline_expert_cards.md §4.4 | 数学学科评课标准卡 |
| lesson_type_rubrics.md §1.1 | 新授课四环节 |

两项例外须保留：「（要点概述，非课标原文）」是事实声明，非编写指引；统一收尾句「条目原文以《XX课程标准（2022 年版／2017 年版 2020 年修订）》纸质版为准」是完成态结论。其余带括注、编号、自陈语气的句子交付前删除或改写。交付前扫描：无文件名、无内部编号、无【待核实：结构名未回查】、无禁用表述，且四行齐备均为完成态实句。

## 六、与技能流程的接口

本文件为新增参考文件，不改动主流程与其他文件，仅在四处生效。

| 接口位置 | 旧写法的问题 | 新写法 | 交付检查点 |
| --- | --- | --- | --- |
| Step 1 学科定位卡「内容要求／学业要求条目」栏 | 要求逐字原文，取不到即「待核实」 | 按第二节四行句式整体填写 | 四行齐全、逐句标注、无编号 |
| 基本信息表「课标依据」行 | 只写版本名 | 课标全称＋版本＋主题／学段＋统一收尾句 | 以固定句式收尾 |
| 附录 G「课标条目出处」行（模板对应「条目核验状态」行） | 罗列下载与未取得说明 | 只写条目出处行原文，可附结构名称 | 无链接、无过程自述、无【待核实】 |
| 议课方案「支持性证据准备」 | 把逐字核验写成待办 | 纸质版课标列为现场比对证据，写明「现场查阅课标纸质版进行逐字比对」 | 比对在议课环节，报告保持完成态 |

四处共同口径：离线可得、完成态实句、不杜撰原文与编号、不交代联网取数过程；旧版残留「待核实」类提示一律以第二、三节写法替换。

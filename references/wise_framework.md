# WISE 课堂研究框架 · 六大策略 · 一率三度

> 来源：胡小勇 主编《问课：智慧课堂教研指南》
> - 第2章「以WISE框架透视课堂」（WISE 四层 + 六大策略 + 一率三度）
> - 第8章「深度解读：以洞察现象透视深层逻辑」（四层框架的细化与教研工具）
>
> 用途：评课 Step 3「WISE 四层透视」的核心工具表；成效判级的唯一标尺。

## 0. 框架总览

WISE 以「迈向深度教学理解」为核心理念，把模糊的"好课"变成可观测、可研究的对象，分为四个递进层次：

| 层 | 名称 | 指向 | 观察/分析对象 |
|----|------|------|---------------|
| **W** | 教学结构层 | 可勾勒的框架 | 课堂要素结构（教学主体/教学内容/课堂环境）+ 教学组织结构（空间/时间/学习形式） |
| **I** | 教学行为层 | 可刻画的过程 | 教师行为（言语/身体/技术操作）+ 学生行为（ICAP）+ 互动行为（师生/生生/人技） |
| **S** | 教学策略层 | 可解释的意图 | 六大策略：教学设计 / 授导互动 / 思维激发 / 评价反馈 / 课堂调控 / 技术融合 |
| **E** | 教学成效层 | 可感知的价值 | 一率三度：知能达成度 / 过程参与度 / 心智生长度 / 素养覆盖率 |

**递进逻辑**：结构决定行为 → 行为体现策略 → 策略影响效果 → 效果彰显价值。

> 评课提示：分析时必须按此顺序推进。**跳层**（如看到"课堂热闹"直接下"素养达成好"的结论）是本框架最忌讳的误用。

## 一、W 课堂结构层（可勾勒的框架）

教学结构并非教学环节的罗列，而是从整体视角呈现课堂的构成要素与组织形态。

### 1.1 课堂要素结构

#### （1）教学主体：师—生—机三元主体

| 主体 | 问课维度 | 评课观察点 |
|------|----------|------------|
| 教师 | 学科背景 | 学科背景是什么？是否接受过本学科专项培训？ |
| 教师 | 教学经验 | 教龄多长？是否有不同学段/学科教学经验？ |
| 学生 | 学段年级 | 本节课面向哪个学段？具体几年级？ |
| 学生 | 认知特点 | 学习风格及知识基础水平如何？是否有特殊学习需求？ |
| 机器 | 技术设备种类 | 本节使用哪些技术/工具？技术使用是否顺畅？ |

#### （2）教学内容

| 问课维度 | 评课观察点 |
|----------|------------|
| 学科属性的挖掘深度 | 是否引导学生细读关键细节，挖掘学科内涵以实现价值引领？ |
| 课型特征的实施匹配度 | 复习课是否用思维导图/知识图谱整合单元知识，而非按教材顺序重讲？ |
| 教材版本的编排逻辑适配性 | 使用教材情境时，是否进行本土化改编？ |
| 单位课时知识容量的合理性 | 45 分钟是否精选 2~3 个重难点以确保深度学习，而非塞入 5 个以上导致认知超载？ |

#### （3）课堂环境

| 问课维度 | 评课观察点 |
|----------|------------|
| 物理空间的功能适配性 | 是否选择了支持相应学习活动的空间（如编程课是否一人一终端）？ |
| 班级文化的氛围适配性 | 小组竞赛时，师生是否共同制定明确规则？ |
| 师生关系的良性互动性 | 学生出错时，教师是引导全班分析错误原因并肯定思考价值，还是直接批评？ |

### 1.2 教学组织结构

#### （1）空间组织（座位布局）

| 布局 | 适配场景 |
|------|----------|
| 行列式 | 知识新授、习题讲评等以教师讲授为主的课堂 |
| 小组式 | 小组讨论、项目式学习等强调同伴协作的活动 |
| U型 | 专题研讨课、成果展示课、口语交际等需要集中交流的活动 |
| 环形 | 阅读分享、头脑风暴等注重全员平等互动的环节 |
| 工作站式 | 理科实验、美术手工、综合实践等操作性较强的任务 |

| 问课维度 | 评课观察点 |
|----------|------------|
| 与教学目标的适配性 | 开展小组合作探究时，桌椅是否调整为小组式或U型，使学生能面对面讨论？ |
| 学习可见性与互动可能性 | 采用U型布局时，是否控制座位间距，确保后排学生能听清、视线无遮挡？ |

#### （2）时间组织

教学事件可分四阶段：

| 教学阶段 | 教学事件 |
|----------|----------|
| 导入阶段 | 引起注意、唤起兴趣和动机、提出教学目标、新课概览 |
| 新知学习 | 回忆旧知、处理信息、聚焦注意力、采用学习策略、练习、评价反馈 |
| 结束阶段 | 小结与复习、知识迁移、再次激励和结束 |
| 评价阶段 | 评估表现、反馈与补救 |

| 问课维度 | 评课观察点 |
|----------|------------|
| 教学环节的完整性 | 本堂课可划分为哪些教学环节？是否完整？ |
| 教学环节的时间分配 | 45 分钟中导入是否控制在 5 分钟内？新知学习是否占 30 分钟以上？ |
| 关键事件的时间保障度 | "知识迁移"是否预留独立时段（如 8~10 分钟）并设计真实情境任务？ |

#### （3）学习形式组织

| 问课维度 | 评课观察点 |
|----------|------------|
| 学习形式与需求匹配性 | 简单计算题是否安排独立完成？复杂探究任务是否采用小组合作？ |
| 集体教学与个性化指导的平衡性 | 集体讲授后，是否针对学困生点对点辅导，或组建"学习互助小组"？ |
| 边缘学生参与的激发性 | 小组任务中，是否为学困生分配具体可操作的任务，确保有效参与？ |

## 二、I 课堂行为层（可刻画的过程）

> 原则：机器做其所长（海量多模态行为数据的编码统计），人类做其所善（行为的情境关联与意义阐释）。

### 2.1 教师行为

| 行为类型 | 问课维度 | 评课观察点 |
|----------|----------|------------|
| 言语行为 | 适配度 | 教师言语行为（组织管理/知识讲授/互动引导/评价反馈/情感沟通）时长分配与教学目标的适配度如何？ |
| 身体行为 | 覆盖面 | 巡视指导、目光关注是否做到均衡公平？ |
| 技术操作行为 | 融合度 | 技术工具使用是否造成学生认知负荷超载？ |

### 2.2 学生行为（ICAP 框架）

| 学习方式 | 外显行为 | 认知结果 |
|----------|----------|----------|
| 被动学习 | 听讲/阅读文章/观看视频但不做指令外的事、全班朗读整篇、胡乱回答 | 回忆 |
| 主动学习 | 做笔记、暂停/播放/快进视频、朗读部分重要段落、仅表示同意或不同意的回答（无新观点） | 应用 |
| 建构学习 | 用自己的话解释、提出新观点/问题（课堂材料中没有的信息） | 迁移 |
| 交互学习 | 与同伴/老师等的多轮建设性对话 | 共同创造 |

| 问课维度 | 评课观察点 |
|----------|------------|
| 言语行为参与度 | 学生的主动发言内容能否反映深度学习的发生？ |
| 身体行为专注度 | 学生整体专注度如何（专注/走神/趴桌时长占比）？ |
| 技术交互行为效度 | 学生使用终端的实际效度如何？ |

### 2.3 互动行为

#### （1）师生互动：弗兰德斯互动分析系统

| 分类 | 具体描述 |
|------|----------|
| 教师言语·间接影响 | 接受学生的感受（非评判性接纳） |
| 教师言语·间接影响 | 表扬或鼓励 |
| 教师言语·间接影响 | 接受或采纳学生的主张（重复、澄清、发展学生观点） |
| 教师言语·间接影响 | 提问（关于概念性或程序性知识的问题，目的是让学生回答） |
| 教师言语·直接影响 | 讲授（列举事实、提出看法、表达观点、设问） |
| 教师言语·直接影响 | 给予指导或指令 |
| 教师言语·直接影响 | 批评或维护权威性 |
| 学生言语 | 学生被动回答（回应教师）／学生主动发言 |
| 沉寂或混乱 | 停顿、短暂沉默或表述不清，交流活动无法被观察者理解 |

> 评课用法：统计教师**间接影响言语**占比。间接影响占比高，通常说明课堂更开放；但**不要单凭比例下结论**，须结合具体话语内容判断是否存在"多轮建设性对话"。

#### （2）生生互动

| 问课维度 | 评课观察点 |
|----------|------------|
| 生生互动协同度 | 学生间观点反驳与补充能否反映深度思考的发生？ |

#### （3）人技互动

| 问课维度 | 评课观察点 |
|----------|------------|
| 人技互动适配度 | 学生与机器互动的深度如何？交流的重点是什么？ |

> 区分：技术操作（单向使用工具）≠ 人技互动（技术作为具有交互逻辑的学习伙伴，与师生形成双向协同的认知过程）。

## 三、S 教学策略层（可解释的意图）

教学策略层把离散的行为数据转化为连贯的教学图景，实现从"发生了什么"到"为什么这样"的意义探究。

> ⚠️ **本层是"意图错位"诊断的主战场**。每项策略不仅要判断"做没做"，更要追问"这一步究竟想达成什么、实际达成了什么"。

### 3.1 教学设计策略

| 检核维度 | 评课观察点 |
|----------|------------|
| 教学目标可达性 | 目标难易是否与当前大多数学生的实际水平相匹配？ |
| 核心内容关联性 | 各知识点是否被有意识连接，而非孤立散落？ |
| 教学结构系统性 | 是否具备支撑有效学习的关键环节，且环节功能明确？ |

**教研深化（第8章）**：目标解码（把素养目标转为可观察行为）→ 证据定义（明确"做到什么程度算达成"）→ 任务逆向设计（设计能生成预设证据的核心任务）→ 支架序列化（拆解为有梯度的活动并提供工具）→ 闭环复盘（依据课堂证据检验目标达成）。

**意图错位**：误将"活动参与"＝"素养表现"；目标与证据不关联；任务好玩但与目标无关。

### 3.2 授导互动策略

| 检核维度 | 评课观察点 |
|----------|------------|
| 授导逻辑清晰度 | 重难点讲解是否突出？时间分配是否合理？ |
| 授导方式多样性 | 能否依据课堂任务灵活切换授导形式？ |
| 互动结构有效性 | 各类互动是否指向重难点的理解？是否存在形式化互动倾向？ |

**教研深化（第8章）**：问题链设计（按逻辑顺序：先确认事实→原因分析→价值判断→迁移应用）→ 倾听追问循环（澄清/探因/质疑/拓展四类追问 + 等待时间）→ 搭建话语脚手架（"我赞同他的观点，同时补充……""我不同意，因为……"）→ 思维对话整体复盘。

**意图错位**：误将"问题多"＝"密度高"；误将"随机追问"＝"问题链"；误将"连环追问"＝"深度引导"；误将"套用句式"＝"学会表达"。

### 3.3 思维激发策略

| 检核维度 | 评课观察点 |
|----------|------------|
| 提问方式丰富性 | 是否以真实情境为载体，提供问题探究入口？ |
| 思维指向高阶性 | 问题能否推动学生展开思辨性与创造性的认知活动？ |
| 思维过程引导性 | 是否依托逻辑递进的问题链条，为学生搭建连贯思考支架？ |

**教研深化（第8章）**：冲突点定位（找出易错处，即可能产生认知冲突的点）→ 冲突情境设计（反例/两难/对比案例，让学生意识到自己的想法）→ 冲突解决引导（收集新证据、辩论、建模）→ 概念转变验证（变式迁移 + 自述转变过程 + 前后测对比）。

> 理论锚点：问题难度应落在**最近发展区**（学生跳一跳够得着），才能激发思维。

**意图错位**：误将"教材难点"＝"学生冲突点"；误将"教师预设"＝"学生前概念"；误将"有趣"＝"认知冲突"；误将"辩论过程"＝"概念转变"；误将"当堂答对"＝"概念扎根"。

### 3.4 评价反馈策略

| 检核维度 | 评课观察点 |
|----------|------------|
| 评价内容聚焦性 | 教师的评价是否均为盲目鼓励，与学生实际表现不符？ |
| 反馈指向明确性 | 反馈能否帮助学生认清认知不足，并促进主动反思？ |
| 反馈时机及时性 | 反馈能否在学生困惑或偏差时及时介入？ |

**教研深化（第8章）**：量规前置设计（共建 3~5 条"我能…"标准，让学生试做后修正）→ 自评/互评嵌入（关键节点自评 + 同桌"肯定+建议"句式互评）→ 教师反馈升级（过程指导型反馈，而非仅对错判定）→ 反馈效果闭环（迭代追踪，对比修改前后作品）。

**意图错位**：误将"给了量规"＝"学生明白标准"；误将"评了"＝"评了"；误将"互评很热闹"＝"标准内化了"；误将"给了评语"＝"给了指导"；误将"反馈发下去了"＝"反馈生效了"。

### 3.5 课堂调控策略

| 检核维度 | 评课观察点 |
|----------|------------|
| 课堂秩序稳定性 | 课堂整体纪律如何？能否有效把控？ |
| 课堂节奏合理性 | 各环节节奏是否贴合学情？能否为学生预留充足时间？ |
| 课堂氛围正向性 | 是否运用积极合适的言语，构建安全、尊重、合作的氛围？ |

**教研深化（第8章）——课堂调控决策矩阵**：面对调控时机，先锚定"优先意图"与"可妥协意图"，再设定"触发证据阈值"，最后决策并复盘证据是否达标。

| 场景示例 | 锚定优先意图 | 可妥协意图 | 触发阈值 | 决策行动 |
|----------|--------------|------------|----------|----------|
| 小组合作超时3分钟 | 允许深度协商 | 时间控制 | ≥70%小组有论证链→延长；<30%实质讨论→终止并讲解 | 宣布再给2分钟并要求每组准备一个重点证据 |
| 齐答顺利准备推进 | 确保学生理解 | 教学进度 | 教师扫视发现后排3人未张口 | 同桌互查，关注未张口者，后续点名 |
| 后排学生走神 | 保障关键内容输入 | 全员同步专注 | 走神人数≤10%且核心内容还剩2分钟 | 提高音量、快讲后同桌互述，课后询问 |

**意图错位**：误将"多数人懂"掩盖"少数人没懂"；调整节奏靠感觉而非学生真实状态。

### 3.6 技术融合策略

| 检核维度 | 评课观察点 |
|----------|------------|
| 技术使用适切性 | 技术是否为本节课确实所需？是否"为了用技术而用技术"？ |
| 技术融合成熟度 | 技术能否帮学生更好地理解内容、参与互动，是否用在关键学习点上？ |
| 技术伦理导向性 | 使用技术时是否提醒学生注意隐私和信息安全？ |

**教研深化（第8章）——人际互动强制设计检查表**：每个用技术的环节后面都要加上人际互动，按"个人完成任务→小组分享讨论→全班总结提炼"操作。检查四问：

| 检查维度 | 关键问题 | 强制触发 |
|----------|----------|----------|
| 任务非独占性 | 学生能否独自完成全部技术操作而无须交流？ | 应为"否"（两人一台平板轮流操作） |
| 议题分歧性 | 技术产出是否天然生成至少两种合理但冲突的观点？ | 应产出多元结果 |
| 角色依赖设计 | 是否明确分配角色（质疑者/整合者/证据员）使互动不可替代？ | 应为"是" |
| 教师干预锚点 | 是否预设了教师介入的"互动质量信号"？ | 应有锚点 |

**技术融合检验标准**：
- **更深入**：技术使用是否引发更多追问、更长对话链、更多元观点碰撞？
- **更公平**：技术介入是否让沉默的学生获得表达机会，让边缘视角被看见？
- **更高效**：技术是否缩短"从问题到思考"的路径，而非让师生陷入操作与调试的干扰？

**意图错位**：误将"技术操作流畅"＝"融合成功"；屏幕成为"第三堵墙"（教师全程面向屏幕，眼神交流中断）；技术喧宾夺主（学生只顾点击拖拽，忘记与同伴讨论）；数据反馈无人回应。

## 四、E 教学成效层（可感知的价值）—— 一率三度

> 核心任务：在教师的"教"与学生的"学"之间建立可信的证据关联。
> ⚠️ 本框架**不使用分数**。四维各作质性三档判定。

### 4.1 质性三档判级模板（本技能的判级标准）

| 档位 | 判据 | 写作模板 |
|------|------|----------|
| **充分** | 有 2 项以上独立可观察证据 | 「充分 —— 观察到 A（环节X）与 B（环节Y），二者共同说明……」 |
| **部分** | 有 1 项证据，或表现有反复、不延续 | 「部分 —— 观察到 A（环节X），但在环节 Y 未见延续，说明……」 |
| **未见** | 记录中未观察到相关表现 | 「未见 —— 记录中未观察到相关表现（如需判定，建议补充观察 X 环节）」 |

**判定纪律**：
- 每个判定必须紧跟现象依据，格式为「档位——因为观察到……」
- **禁止**"得分偏低""不合格"等常模化表述
- **禁止**用判定做教师横向比较或排名

### 4.2 知能达成度

| 核心问题 | 延伸问题 | 数据来源 |
|----------|----------|----------|
| 相关知识能调用吗？ | 学生回答问题时反应速度如何？ | 课堂观察（回答速度）；随堂检测；学习单 |
| 知识/技能用对了吗？ | 练习题正确率如何？ | 随堂检测；学习单；课后练习 |
| 知识/技能用好了吗？ | 重难点知识的迁移应用效果如何？ | 表现性任务；学生作品；口头汇报 |

### 4.3 过程参与度

| 核心问题 | 延伸问题 | 数据来源 |
|----------|----------|----------|
| 学生主体性如何？ | 学生是一味听讲，还是有思考和练习的时间？ | 课堂观察（师/生主导时长） |
| 身体运动融入如何？ | 学生身体动作能否有效融入学习环节？ | 课堂观察（学生身体动作） |
| 技术使用如何？ | 学生使用技术是为完成任务，还是更多用于娱乐？ | 终端使用日志；屏幕录制 |

**课堂类型参考（按师生时间比）**：

| 课堂类型 | 课堂特征 | 适用场景 |
|----------|----------|----------|
| 教师主导型（7:3） | 教师讲授、示范为主，学生应答、练习为辅 | 新概念引入、难点突破、技能示范 |
| 平衡型（5:5） | 讲授与活动交替进行，师生互动频繁 | 常规课、多数新授课 |
| 学生主导型（3:7） | 学生探究、展示、互评为主，教师仅作引导 | 复习课、项目式学习、实验课 |

> ⚠️ **学生主导占比并非越长越好**。低年级（一至三年级）单次主导不超过 10 分钟，高年级（四年级及以上）单次主导 15~20 分钟。

**身体姿态观察评价表（具身学习）**：

| 评价维度 | 观察指标 | 具体行为表现 | 计分方向 |
|----------|----------|--------------|----------|
| 姿态同步性（身体是否回应思维） | 思考态 | 问题提出后身体前倾、眉头微蹙、眼神聚焦 | 正向 |
| | 认同态 | 倾听同伴发言时微微点头、眼神跟随发言者 | 正向 |
| | 游离态 | 后仰呆坐、眼神飘忽、频繁变换坐姿 | 反向 |
| 动作表征性（身体是否诠释思维） | 概念外化 | 用手势模拟数学平移/旋转、用肢体表现科学过程 | 正向 |
| | 工具操作 | 操作学具时动作有目的性，符合任务逻辑 | 正向 |
| | 机械模仿 | 仅按指令抬手，动作与理解脱节 | 反向 |
| 操作专注度（身体是否卷入任务） | 持续投入 | 动手实验/练习时手、眼、脑协调，动作连贯 | 正向 |
| | 目标指向 | 眼神追随手部操作，动作围绕任务展开 | 正向 |
| | 随意中断 | 动作无序、频繁停顿、东张西望 | 反向 |
| 互动自然度（身体是否参与交流） | 协作倾向 | 讨论时自然围拢、指向同伴作品、用手势辅助表达 | 正向 |
| | 倾听姿态 | 侧耳倾听、转身面向发言者、身体微微前倾 | 正向 |
| | 社交僵硬 | 交流时身体僵直、只靠语言输出、无肢体配合 | 反向 |

> 观察时机：建议在关键教学环节（探究活动、小组讨论、问题解决）进行**定点观察**，而非全程平均。
> 综合判断：高融合度＝姿态随思维流动，动作能表征概念，身体深度卷入任务；低融合度＝身体僵硬或松散，动作与思维脱节，身体未真正"进场"。

### 4.4 心智生长度

| 核心问题 | 延伸问题 | 数据来源 |
|----------|----------|----------|
| 学习兴趣如何？ | 学生能否积极参与教学活动并表现学习热情？ | 课堂观察（学生表情/音调） |
| 思维品质如何体现？ | 学生的发言/作品能否体现逻辑性、批判性与创造性？ | 课堂观察（发言内容）；学生作品 |
| 主动发问意愿如何？ | 学生主动发问意愿是否强烈？是否敢于表达见解？ | 课堂观察（主动质疑行为）；学习反思 |

**八条评价策略**：

| 策略类型 | 策略名称 | 具体做法 | 评价维度 |
|----------|----------|----------|----------|
| 过程捕捉（让思维"可视化"） | 思维轨迹留痕 | 要求写下解题的"卡壳点"或"转折点"；阅读时标注批注，记录疑问、联想或共鸣 | 思维品质 |
| | 困惑捕捉机制 | 把"提出困惑"作为固定环节，如"写下一句话的困惑"；每组带回一个"还没弄懂的问题" | 主动发问意愿 |
| | 情绪状态记录 | 关键环节观察情绪反应；用"情绪温度计"（手势打分）记录投入程度 | 学习兴趣 |
| | 课堂微问卷 | 每课/每单元用 2~3 个简单问题收集反馈（"最吸引我的环节""主动提问次数"） | 兴趣/发问/参与度 |
| 工具辅助（让内隐变"可测"） | 思维品质观察清单 | 听课时定点记录思维表现（广度/深度/灵活性/独创性）的频次 | 思维品质 |
| | 课后两分钟"心跳时刻" | 下课前提问："今天让我心跳加速的瞬间是……""我发现自己开始思考……" | 兴趣/发问 |
| 主体多元（让学生参与评价） | 学生自评表 | 简易自评工具（表情符号/等级）：反思兴趣、思维投入、发问意识、思维突破 | 综合思维 |
| | 同伴互评"发现的眼睛" | 引导学生互相表扬："我要表扬___，因为他提出了一个有价值的问" | 主动发问/思维品质 |

**建立"好问"课堂文化的实施方法**：

| 课堂阶段 | 教师引导问句 | 作用 |
|----------|--------------|------|
| 新课开始前 | "你想研究什么？想知道什么？" | 引导学生关注本节课内容和目标 |
| 新知识学习结束后 | "你遇到哪些困难？有什么疑问？" | 引导学生表达困惑并提问，鼓励同伴互助解决 |
| 课堂结束前 | "你还有什么新问题？新发现？" | 引导学生带着问题走出课堂，培养批判性与创新思维 |

### 4.5 素养覆盖率

| 核心问题 | 延伸问题 | 数据来源 |
|----------|----------|----------|
| 培育了哪些核心素养？ | 与课标要求对标，本堂课的素养覆盖率如何？ | 教学设计方案（教学目标）；课堂观察 |
| 素养培育发展性如何？ | 从单元/学期来看，是否覆盖学科核心素养的全部维度？ | 多个教案；多节课录像 |

**教学目标关联性评价表**：

| 评价阶段 | 评价维度 | 评价指标 | 具体观测点 |
|----------|----------|----------|------------|
| 课前（设计） | 目标合理性 | 课标匹配度 | 本课目标是否对应课程标准或学科核心素养要求？ |
| | | 学情适应性 | 目标是否建立在学生已有知识基础上，处于最近发展区内？ |
| | | 表述清晰度 | 目标是否具体、可测，包含行为动词和表现条件？ |
| | 目标—活动一致性 | 环节指向性 | 每个教学环节是否至少对应一个具体教学目标？ |
| 课中（实施） | | 资源适切性 | 选用的素材、案例、技术工具是否服务于目标达成？ |
| | | 时间保障度 | 核心目标是否获得充足的课堂时间？ |
| | 目标—过程动态性 | 生成处理度 | 学生出现与目标相关的生成性问题时，教师是否有效回应？ |
| | | 证据可见性 | 学生是否有机会（练习/表达/作品）展示目标达成情况？ |
| 课后（成效） | 目标—结果一致性 | 评价对应性 | 当堂检测/课后作业是否直接对应预设目标？ |
| | | 目标达成度 | 大多数学生是否达成了本课的核心目标？ |

> ⚠️ 素养培育遵循**长期主义**：一堂课难以覆盖学科核心素养的全部方面，应以单元或学期为单位分析发展性与系统性，不以单课时苛求全覆盖。
> 设计要点：①一课一得（准确对标，避免贪多求全）；②素养审计（每个活动对应什么素养，保证有载体有路径）；③关注素养间的关联性与递进性，融入单元整体脉络。

## 五、快速自检：四层是否"跳层"

| 检查 | 自问 |
|------|------|
| W→I | 我描述的行为，是否先交代了它发生的结构条件（环节、空间、时间、形式）？ |
| I→S | 我判断的策略意图，是否有具体行为作为依据？还是凭推测？ |
| S→E | 我给的成效判定，是否基于学生实际表现，而非教师的"教"？ |
| E→W | 成效不佳时，我是否回溯到了结构层找原因，而非停在"学生基础差"？ |

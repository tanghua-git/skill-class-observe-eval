# 教研真问题与差异化发问

> 来源：胡小勇 主编《问课：智慧课堂教研指南》第7章「确定目标：锚定真问题，开启精准教研」
> 用途：评课 Step 5《议课组织方案》的核心工具；报告第六节「差异化发问设计」的句式来源。
>
> 核心理念：**教研关键不在于"评得多细"，而在于"问得是否到位"。**

---

## 一、教研真问题的判定

### 1.1 真问题的两个特征

教研的真问题应具备：①**源于真实课堂实践与困境**，有现实针对性；②有**清晰的研究边界和可操作的研究路径**，能够落地实施。

### 1.2 假问题 vs 真问题对照

| 操作 | 假问题 | 真问题 |
|------|--------|--------|
| 加主语、定场景、写动作 | 提高学生的课堂参与度 | 四年级语文课，每到小组讨论环节，有男生就开始低头摆弄文具，怎么设计 3 分钟内的全员开口任务？ |
| 定策略、带方法 | 小学英语词汇教学策略 | 把常规抄写改成游戏化复现策略（单词卡片、你画我猜），连续三周，班级平均错词能否降到 4 个以下？ |
| 定周期、带工具、能验证 | 培养学生自主学习能力的课堂策略 | 五年级英语早读，三分之一学生只张嘴不出声。用"5分钟微任务+同桌互查"连做两周，能不能把开口率提升到 90%？ |

### 1.3 教研问题防伪检验表（议课选题自检）

| 验一验 | 是/否 |
|--------|-------|
| 是否摆出了具体的数字或看见的具体行为，而不是只用"我觉得"作为开头？ | |
| 这个问题是否已经小到了某一个单元、某一节课甚至某一道错题上？ | |
| 这个问题是不是你亲眼看见、亲手批改、亲耳听到的，而不是转述别人的判断？ | |
| 在想办法之前，你是否已经弄清楚了学生的卡点在哪里、为什么不会？ | |
| 你是否还原过学生当时的思考路径？ | |
| 你是否排除过其他可能的原因？ | |
| 要想验证这个办法，你是否准备好了具体的清单、表格或关键的问题句式？ | |

### 1.4 探寻教研问题的五种策略（了解即可，用于议课选题说明）

| 策略 | 从哪找 | 转化关键技巧 |
|------|--------|--------------|
| **课堂实践** | 观察自身课堂、观察同侪课堂、研析专家课例 | 加对象（中等生/学困生）、定场景（小组讨论/复习课）、定策略（具体可实践的方法）、可观测（把"兴趣高"变成"举手次数/发言时长"） |
| **教育文本** | 课程标准与政策文件、教材与教学资源、学生作品 | 课标对标与认知分析；失分归因与策略对应；学科互嵌、目标并进 |
| **交流分享** | 与专家、领导、同事、学生、家长交谈 | 提炼经验；资源整合（从割裂到融合）；剥离现象思考解法；转化落差（从话语到行动） |
| **技术分析** | 课堂伴随性数据、平台学情报告 | 证据锚定与策略对应；AI 与人工共同评价；错题画像与靶向干预 |
| **学校发展** | 学校重点任务与改革方向 | 从学校改革方向中定位个人教研坐标 |

### 1.5 教研问题防伪：四个常见陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| 将模糊感受直接当作问题 | "学生参与度不高" | 应用具体要素将其锚定（加对象/定场景/可观测） |
| 将宽泛领域定为教研问题 | "小学英语词汇教学策略" | 收缩为可操作、个性化切口 |
| 对策先行 | 直接给"优化设计""加强互动" | 首先追问现象根源 |
| 将研讨共识视作终点 | 讨论热烈但无后续 | 转化为可行动的微小实践 |

## 二、差异化发问（核心工具）

### 2.1 什么是差异化发问

在教研中基于不同的观察视角、研究意图与改进目标，有意识地**区分和使用不同类型、层次的提问策略**，以精准定位教学真问题、激活深度思考、推动实践迭代。其对立面是"这堂课整体不错""课堂气氛挺好"这类笼统评价。

### 2.2 六种发问类型（核心句式库）

| 发问类型 | 核心意图 | 问题句式示例 |
|----------|----------|--------------|
| **场景发问** | 还原教学现场，关注学生学习真实发生的过程与细节 | 「在××环节，教师提出了当时学生的反应是怎样的？」「哪些学生的表现与预期有差异？可能是什么原因导致的？」 |
| **精准发问** | 将宽泛的教学目标或问题，拆解为具体、可观测、可操作的教学行为或学习表现 | 将"学生参与度不高"转化为「小组讨论时，具体是哪些学生没有发言？」「教师提供了哪些话语支架或任务分工来促进学生参与？」 |
| **适配发问** | 追问教学设计与学生实际认知的匹配度 | 「这个探究任务，处于学生认知的舒适区、发展区，还是恐慌区？」「教师在问出那句话之后，学生有无出现认知冲突？」 |
| **主体发问** | 从学生视角出发，发现教学设计中可能被忽略的难点 | 「如果我是坐在第三排的那个学生，这个环节我可能卡在哪儿？」 |
| **建设性发问** | 指向行动、赋能改进，自然引向"我们可以怎么做" | 「为了让学生更深入理解××，除了教师讲授，我们还可以设计怎样的学生自主探究任务？」 |
| **理论发问** | 将教学现象与教育理论或课标理念建立联系 | 「这个做法背后是什么原理？对应课标哪条内容？」「这体现了什么学习原理？」 |

### 2.3 有效差异化发问的四大特征

| 特征 | 内涵 | 检验方法 |
|------|------|----------|
| **具体性** | 锚定证据，脱离空谈。提问要包含"在哪个环节""哪些学生""用了什么材料""学生说了什么"等要素 | 将"学生参与度不高"转化为"在小组讨论××时，第三组的两名同学始终未发言，教师当时给予了什么提示或支持？" |
| **探究性** | 追因溯果，开放对话。避免简单的是非判断，揭示现象背后的原因、机制与可能性 | 追问"是操作步骤不清晰，还是没有掌握测量工具的使用方法？" |
| **层次性** | 循序渐进，立体深挖。呈现"**现象 → 行为 → 原因 → 策略**"的递进逻辑 | 写下问题链，检查是否跳过现象直接归因，或仅停留在诊断性问题 |
| **建设性** | 指向行动，赋能改进。以"如何优化""可以尝试""怎样调整"等结尾 | 每个诊断性问题后紧跟"我们可以怎么做" |

### 2.4 差异化发问的三大误区与应对（重要）

#### 误区一：发问无焦点
一个问题中包含很多追问，导致被提问者只能选择其一回答，或在多个话题间跳跃而没有深入追击。
> **应对：单问原则 + 问题链设计**——每次只提一个问题，聚焦单一事实、单一行为、单一意图。将有逻辑关联的多个问题，按"现象→行为→原因→策略"的顺序拆解为递进式追问，逐个抛出。
>
> **转化示例**：
> ❌「这节课的小组合作效果如何？学生有没有真正讨论起来？教师巡视时给了哪些指导？下次怎么改进？」
> - 第一问（场景发问）：「在第三个小组讨论环节，我观察到教师在第三组停留了大约 1 分钟，当时师生之间具体交流了什么内容？」
> - 第二问（精准发问）：「这段对话中，教师提供了哪几个具体的追问或提示语？」
> - 第三问（适配发问）：「这样的提示方式，对于该组平时不爱发言的那名同学，是否起到了支持作用？」
> - 第四问（建设性发问）：「这种'追问促学'的策略，我们是否可以提炼成一种可迁移的小组指导方法？」

#### 误区二：发问缺证据
提问只依赖"感觉""好像""总觉得"等模糊感受，讨论建立在主观印象上，难以达成共识。
> **应对：先事实，后问题（强制前置证据链）**——提问前必须先陈述一条可观察、可验证的具体事实，再用"我注意到……我想了解……"的句式衔接。同时锚定时空坐标（哪个环节/哪些学生/何种反应）。
>
> **转化示例**：
> ❌「感觉学生没掌握好，是不是讲得太快了？」
> ✅「我注意到在概念讲解后的独立练习环节，有 6 名学生在 2 分钟内没有动笔。我想了解，当时这几名学生是在思考，还是在题意理解上遇到了困难？」
>
> ❌「好像有几个学生一直没跟上。」
> ✅「在讲解'力的分解'例题时，第三排靠窗的两名男生一直在低头翻书，没有看黑板。我想了解他们是前面的知识点还没弄懂，还是这道题的难度超出了他们当前的接受水平？」

#### 误区三：发问无跟进
止于"哪里有问题"而不追问"可以怎么做"，问题缺少建设性。
> **应对：「问题+1」原则（每个诊断必须对应一个对策）**——诊断性问题后紧接建设性问题，用"我们"替代"你"，将改进责任从授课教师个体转化为教研共同体。
>
> **转化示例**：
> ❌「这个换算环节学生错误率这么高，你的板书太乱了。」
> ✅「我注意到换算环节的错误集中在'没有呈现换算步骤'。我们是否可以设计一个'换算步骤卡'，让学生在做练习时按步骤操作？或者有没有其他更直观的呈现方式？」

### 2.5 差异化发问自查表（提问前参照、提问后复盘）

| 自查维度 | 具体描述 | 是/否 | 如何改进 |
|----------|----------|:-----:|----------|
| 具体性 | 提问是否锚定在具体的教学环节、学生表现或师生对话上？ | | 追问自己："发生在哪个环节？哪几名学生？他说了/做了什么？" |
| 探究性 | 问题是否以"如何""为何""怎样"等开放式疑问词开头？ | | 将"是不是""有没有"改为"如何""怎样" |
| 层次性 | 问题是否构成"现象→行为→原因→策略"的递进逻辑，而非零散跳跃？ | | 写下问题链，检查是否跳过现象直接归因，或仅停留在诊断性问题上 |
| 单问原则 | 是否一次只提一个问题，避免混杂多个子问题？ | | 拆分长问句，按逻辑顺序逐个抛出 |
| 证据前置 | 是否先陈述了一条可观察的教学事实，再提出问题？ | | 练习"我注意到……我想了解……"句式 |
| 建设跟进 | 是否在诊断问题后，主动跟进一个"我们可以怎么做"的建设性问题？ | | 强制"问题+1"：每个诊断必须紧跟一个"我们可以……" |
| 主体转换 | 是否尝试过从学生视角发问？ | | 将"教师为什么这样教"转为"学生在此处会遇到什么困难" |
| 理论连接 | 是否尝试过将教学现象与某个教育理论或课标理念建立联系？ | | 追问："这个做法背后是什么原理？对应课标哪条内容？" |

### 2.6 不同研讨主题/阶段的优选发问类型

| 研讨主题/阶段 | 优先选用的发问类型 |
|---------------|-------------------|
| 课堂细节复盘 | 场景发问、精准发问 |
| 学情诊断与差异化教学 | 适配发问、主体发问 |
| 教学策略优化 | 精准发问、建设性发问 |
| 教学成果提炼与升华 | 理论发问、适配发问 |
| 新教师听评课 | 场景发问、精准发问 |

### 2.7 不同教研角色的发问步骤与技巧

| 教研角色 | 发问步骤 | 优先发问类型 | 典型提问技巧 | 避雷指南 |
|----------|----------|--------------|--------------|----------|
| **教研组长** | 三步走：①策略萃取（从具体做法提炼可迁移原则）②成果转化（把结论转为可执行行动清单）③理论提升（把教学现象与教育理论、课标理念关联） | 建设性发问、理论发问 | 策略萃取法；成果转化法。例："今天的讨论确定了哪些可下次试点的行动？" | 避免只做主持人，要敢于将讨论推向策略化、结构化 |
| **骨干教师** | 四步走：①认知门槛拆解（追问任务难度与学生能力的匹配度）②行为切片分析（把笼统现象切分到具体教学话语、学生表现或互动节点）③差异适配追问（是否关照不同层次学生）④策略雏形提炼 | 适配发问、精准发问 | 认知门槛拆解法；行为切片法。例："这个探究任务，处于学生认知的舒适区、发展区，还是恐慌区？" | 避免过早给方案，先用问题引导团队归因 |
| **新教师** | 三步走：①现场还原（用提问捕捉被忽略的教学细节）②视角代入（从"如果我是学生"出发）③困惑外化（把真实疑惑转化为问题，向同伴求助） | 场景发问、主体发问 | 代入法；还原法（不评判、只打捞细节）。例："当时学生沉默了几秒？之后谁先举手的？" | 避免不敢提问，也避免直接"审判"授课教师 |

### 2.8 差异化发问工具卡（正反对照）

| 正面发问——典型句式 | 错误提问——提醒对照 |
|---------------------|---------------------|
| 场景发问：在××环节，学生当时的反应是什么？ | 一个问题包含多个追问："学生参与度如何？教师巡视了吗？下次怎么改？" |
| 精准发问：具体是哪些学生/哪句话/哪个动作？ | 依赖模糊印象："感觉学生没掌握好。" |
| 适配发问：这个任务处于学生的哪个区（舒适区/发展区/恐慌区）？ | 只问难度，不问匹配度："这个题是不是太难了？" |
| 主体发问：如果我是学生，我会卡在哪儿？ | 只评教师，不评学情："你这里讲得太快。" |
| 建设性发问：我们可以怎样提炼/迁移/尝试？ | 只破不立："这个问题太开放了，学生答不上来。" |
| 理论发问：这体现了什么学习原理？ | 停留在经验："我觉着这样上挺好的。" |
| 证据前置句式：我注意到……我想了解…… | 先结论，后举证："学生根本不在状态。" |

## 三、从个体感悟到集体设计（选题方法，供议课主持人参考）

### 3.1 教师自我洞察的六个维度

| 维度 | 自我提问导向 | 教研真问题示例 |
|------|--------------|----------------|
| 兴趣驱动 | 追问热爱："我对教学中的什么现象或领域充满好奇？" | "如何设计意象探微学习任务，让高中生真正感受《春江花月夜》的意境之美，而非仅止于背诵？" |
| 短板意识 | 直面困惑："哪个教学环节我总感到棘手？" | "如何基于学情诊断，为'二次函数'单元的不同课时，设计差异化的时间分配与节奏调控策略？" |
| 经验提炼 | 复盘高光："那次特别成功的课是怎么发生的？" | "如何将辩论式学习模式结构化，迁移应用到近代史其他单元的教学中？" |
| 能力聚焦 | 发挥长处："我的核心教学能力优势是什么？" | "如何基于我的板书优势，设计可操作的步骤与工具，帮助学生掌握自主绘制知识图谱的能力？" |
| 背景关联 | 链接宝藏："我的专业背景、业余爱好中，有什么可以成为独特的教学资源？" | "如何利用我的技术特长，开发交互式小应用或动态图表，让学生直观理解统计概念？" |
| 学生盲点 | 观察学生："学生在哪个知识点上反复出错？" | "如何设计可视化互动工具或渐进式作图训练，突破受力分析中的思维盲区？" |

### 3.2 教研问题"落地转化三步法"（微观聚焦）

**单课、单点、单行为**：
- **单课**：划定边界——"在哪一节课里研究？"
- **单点**：锁定靶心——"聚焦这节课的哪个环节/知识点？"
- **单行为**：找准抓手——"观察/改变哪个具体教或学的动作？"

转化路径：①锚定内容（把宏大主题与你正在教的某一单元、某一课紧密绑定）→ ②寻找载体（用一个具体学习任务或学生活动承载该主题）→ ③重构问题（用"在（某单元/某课）中，如何通过（某具体任务/活动）来（达成素养/能力的某具体表现）？"的句式重构）。

### 3.3 三种转化策略

| 策略 | 适用情形 | 做法 |
|------|----------|------|
| **困境拆解法** | "课上得很别扭，但不知从何改起" | 三步拆解：发生在哪个环节 → 学生卡在什么动作 → 原因是什么。自检：转化后的问题能否让人一眼看出哪节课、哪个环节、要改变哪个行为？ |
| **高光复现法** | 有"学生眼睛亮了"的高光时刻但只是感慨 | 捕捉灵光乍现 → 提炼可迁移策略 → 转化为问题。自检：能否把偶然成功转化为"可迁移、可复制的策略原型"？ |
| **盲点倒推法** | 把问题归因于学生 | 转向追问自己的假设："是否默认学生已掌握某个前置知识？"问题从"学生为什么还不会"转为"我还可以换一种怎样的方式让他们学会"。 |

### 3.4 集体教研真问题的六维分析框架

| 维度 | 核心追问 | 转化路径 |
|------|----------|----------|
| 国家政策（为何教研） | 政策落地到我的课堂，遇到的最大阻力是什么？ | 政策具体化 |
| 课程标准（教研什么） | 课标中的"核心素养"在我所教学段的具体表现是什么？ | 课标行为化 |
| 区域规划（依托什么） | 区域推进的重点项目，能解决教学中的哪个具体痛点？ | 资源问题化 |
| 学校特色（为谁教研） | 学校的办学理念/特色文化，如何在学科教学中真正落地？ | 特色课程化 |
| 科组项目（如何教研） | 通过课堂观察，学生在本学科最常犯的、最具体的错误是什么？ | 问题微型化 |
| 群体共识（共同教研） | 组内教师目前普遍感到最困扰、最想解决的"共性痛点"是什么？ | 需求民主化 |

### 3.5 民主协商式教研选题流程（供科组使用）

| 步骤 | 具体操作 | 时长 |
|------|----------|------|
| 自由书写 | 每人匿名写下"本学期我在课堂上最想解决的一个困惑"（写现象，不写概念） | 5 分钟 |
| 归类整理 | 组长收齐后当堂朗读（不记名），按类别归类（课堂管理/知识教学/学生差异/作业评价） | 10 分钟 |
| 民主投票 | 每人投票 1~3 次，选出最希望本学期共同研究的那类问题 | 5 分钟 |
| 聚焦定题 | 得票最高的一类胜出，提炼出一个具体、可操作的教研主题 | 10 分钟 |

## 四、人智协同剖析教研问题

### 4.1 教师需要具备的四种思维

| 思维 | 内涵 | 示例 |
|------|------|------|
| **属性思维** | 对教研问题进行类别归属（知识类型/认知层级/教学行为/学生状态/任务设计/媒介工具/时空） | 把"学生不会做"精准化为"程序性知识执行过程中，步骤的衔接条件提取失败" |
| **语境思维** | 把教研问题锚定在具体时空中（学情语境/课型语境/约束语境） | "我是一名城乡结合部的五年级数学教师，正在上'分数的意义'第三课时。班额48人……" |
| **证据思维** | 从三个维度采集证据：频次证据（普遍性）、典型样本证据（思维断点位置）、对比证据（锁定关键变量） | "全班有32人在第3题出错"（频次）；"这是一名中等生的完整解题过程"（典型样本）；"该班错误率37%，去年同轨班级仅15%"（对比） |
| **批判思维** | 敢于反驳、追问依据，避免不假思索地照单全收 | 三种反驳提示词（见下表） |

### 4.2 三类反驳提示词（与 AI 协同时的自保工具）

| 提示词技术 | 应用时机 | 核心目的 | 提示词范例 |
|------------|----------|----------|------------|
| **反驳指令** | 当 AI 给出过于肯定、好像"唯一的正确答案"时 | 迫使站到对立面，激活被压制的反向证据 | 「请站在相反立场，反驳你刚才给出的归因结论。」 |
| **约束压力测试** | 当 AI 提出需要理想条件才能落地的策略时 | 把理想方案拉回真实教室的约束条件中 | 「请考虑我在没有多媒体设备、班额40人、课时紧张的现实约束下，批判刚才建议的可行性。」 |
| **证据溯源指令** | 当 AI 给出断言式结论但没提供依据时 | 追问结论背后的依据，暴露信息底牌 | 「这个结论的主要依据是什么？是否存在选择性引用案例的嫌疑？」 |

### 4.3 证据类型与采集动作

| 证据类型 | 核心功能 | 教师采集动作 |
|----------|----------|--------------|
| 频次证据 | 确定问题的普遍性，避免将个别学生问题误判为班级共性问题 | 统计某道题的出错人数，或某类错误的占比 |
| 典型样本证据 | 精准定位学生的思维断点发生在哪一步（读题？列式？计算？验证？） | 选取一名中等生的完整解题过程（文字、图片、录音均可） |
| 对比证据 | 控制变量，锁定真因 | 找一组可对比的数据（去年同轨班级、同年级另一班级） |

## 五、教研目标的三类型与 SMART 自检

### 5.1 三类课堂教研目标

| 目标类型 | 问题来源 | 改进指向 | 目标写法示例 |
|----------|----------|----------|--------------|
| **改进型目标** | 教学设计层面的疏漏（内容、任务、问题链本身有问题） | 改进课例 | 设计并验证一组由浅入深、能激发思维冲突的"导学问题链" |
| **发展型目标** | 教师能力层面的短板（提问、诊断、组织、反馈等技能不足） | 发展能力 | 设计并实践一个能引发学生观点碰撞或自我反思的"高阶问题"，并记录学生反应 |
| **愿景型目标** | 职业愿景层面的落差（教学理念、角色定位、专业方向待调整） | 靠近愿景 | 设计并实施包含嵌入式评价任务的课时方案，探索评价结果如何即时调整教学节奏 |

### 5.2 归因陷阱（要警惕的）

| 陷阱 | 表现 |
|------|------|
| 习惯性外归因 | 把"我的问题"归成"别人的问题"（"学校没要求""学生基础差"） |
| 浅表化归因 | 把"现象"直接当成"原因"（"计算错是因为计算能力弱"） |

### 5.3 教研目标自检（SMART）

| 自检问题 | 是/否 |
|----------|:-----:|
| **具体**（Specific）：是否明确聚焦某一课型、某一环节、某一策略？ | |
| **可衡量**（Measurable）：是否有可观测的证据（学生作品、回答、行为、数据）？ | |
| **可实现**（Attainable）：是否在一个教研周期内能够完成？ | |
| **相关**（Relevant）：是否与所得到的真实问题直接相关？ | |
| **有时限**（Time-based）：是否有明确预期完成的时间节点？ | |

**目标指引牌**：「这次教研，我在［　］环节练会了［　］，结束时我能带走［　］。」

> 提示：每一条学生预期表现目标，都应配套一条教师能力发展目标。答不出环节是空想，答不出技能名称是模糊，答不出"可示范"是还没想透。

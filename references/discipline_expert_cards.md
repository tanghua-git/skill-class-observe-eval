# 学科评课专家标准卡库（discipline_expert_cards.md）

> 定位：`class-observe-eval` 学科适配层参考文件，由主文档指针引用；作用＝让评课符合本学科要求、按该学科领域顶级专家标准规划。只登记可核验专家依据、课标锚点、课堂可见事实；Step 1 定学段学科后加载，出处回第六节核对。

---

## 一、口径定义

**1.1 口径（用户已确认）**「顶级专家标准」＝**各学科课标研制／修订组组长及核心成员的公开论述**（课标制定者，同源可核验）；不含名校名师、网络意见领袖、通用教育理论家。姓名／职务／主张只取第六节并带出处，此外 `【待核实】`。

**1.2 三级证据链**

| 层 | 落点 | 允许／禁止 |
|---|---|---|
| ①法定层 课标原文 | ② | 「课标表述为…」；禁混入专家解读 |
| ②专家层 带出处论述 | ③ | 「某某（出处）提出…」；**禁写成课标要求**，禁把转述当原文 |
| ③教研层 观察要点 | ④⑤⑥⑦⑧ | 「观察到…（环节×）」；禁上升为课标或专家主张、禁抽象标签 |



**1.3 四条红线** ①不杜撰：只取第六节带出处，未核验 `【待核实】`，禁编造、禁把网络转述当原文；②不混层：只有课标原文可称「课标要求」；③不拿通用理论或他科量尺当学科标准，观察点须课堂可见；④不假托原著、不串味，领域分层只认《问课》第2、4章。

**1.4 佐藤学表达纪律** 陈大伟《观课议课与教师成长》上篇五(四)引佐藤学：「在讨论中，最重要的是**丢开一切抽象的语言，只说出自己对所观察到的事例的质朴感受和具体的事实本身**」。写「教师是否只回应与标准答案一致的发言」，不写「体现了核心素养」；判断后须紧跟事实。

**1.5 「待核实」规范** 格式 `【待核实：<缺口>】`；触发：专家不在第六节／只有解读主题／课标未回查／学段素养未核／转述载体。格内不写具体主张、不以常识补写；报告写「依据待补／记录中未观察到」。

## 二、三级架构：领域层 → 学科层 → 学段层

**2.1 领域层四分（依据与原著出处）**

| 领域 | 《问课》出处与要点 | 阶梯 | 映射（技能层经验性映射，待核实） |
|---|---|---|---|
| A 人文 | 4-8「基本问题—单元问题—内容问题」；表4-8-1四维＝认知层次／情境依赖／答案属性／课堂作用；基本问题「最有争议性」，内容问题「有明确的答案」 | 三级 | 语文、历史、道法；英语【待核实】 |
| B 理工 | 4-9「老问题—新问题—疑难题」，基于学生认识事物的发展过程；「**当老问题无法解决新情境时，就会产生认知冲突…这是学习发生的关键环节**」；表4-9-2「相同本质、不同表象」 | 三级 | 数学、物理、信息科技、化学、生物学、科学、通用技术；归属【待核实】 |
| C 艺体劳 | 4-8／4-9仅就人文／理工立论；2-3「策略选择需**适配具体学科与课型**…**难以穷尽所有策略**」 | **另设** | 艺术、体育与健康、劳动 |
| D 跨学科／项目 | 4-10「**设计之根却需要深植学科内核，落脚于学科课程标准**」；4-11「抽象出学科的本质追问」；4-12「**从『主题先行』转向『问题驱动』**」「问题—学科链接路径」 | 问题驱动 | 跨学科、项目式 |

> **艺术／体育／劳动不硬塞进人文／理工二分**：硬套即把通用阶梯当学科标准（红线三）。

**2.2 学科层** 首批 4 科（第四节）出完整卡；**第二批 7 科（化学、生物学、科学、英语、道德与法治、历史、地理）已于 v3.3.1 升级为完整卡，见 `discipline_cards_batch2.md` 第 1–7 节**；第三批 6 类仍「骨架版·待深化」，**用户已确认不再建设，为最终状态**。

**2.3 学段层（小／初／高）** 史宁中（义教及高中数学课标修订组组长）：「**内涵一致性、表现阶段性、表述整体性**」〔教育部官网人物报道、《西南大学学报》2022；详六〕。⚠️**数学领域专家层论述**，仅作学段分层类比，**不得写成课标要求、不得外推他科**。约束：2-4「一堂课难以覆盖学科核心素养的全部方面」；4-5三学段良构／劣构问题配比不同（**不写数字**）；1-4「**学科边界仍需由教师把握**」。

## 三、「学科评课标准卡」八字段模板

| 字段 | 层 | 硬性写法 |
|---|---|---|
| ①学科本质 | ③ | 一句话说本学科区别于他科的追问方式；据2-1表2-1-2「是否符合学科本质」、4-11；禁抽象标签 |
| ②法定锚点 | ① | 义教／高中课标核心素养**逐字**表述；「四基」「四能」属专家层不得入栏；其余 `【待核实：课标原文未回查】` |
| ③专家视角 | ② | 第六节名单逐条带出处＋核验状态；转述注「讲座纪要载」；仅解读主题者写「主张原文【待核实】」 |
| ④学科特有观察点 | ③ | **5–8条课堂可见事实**，句式「教师是否…／学生是否…」；守1.4；不署专家名 |
| ⑤学科特有误区 | ③ | 外行用通用尺子量本学科常犯的错，写「把X误当Y」 |
| ⑥学段进阶 | ①③ | 小／初／高三档各写「锚点差异＋焦点差异」，**不许只换年级标签**；小学无独立学科写明不适用并转介 |
| ⑦问题类型适配 | ③ | 人文三级／理工三级／艺体劳另设／跨学科问题驱动，标《问课》章节 |
| ⑧议课请谁 | ③ | 学科同侪／科组带头人；据3-1「1主N辅」参研智能体（教育学者、教学法专家、区域教研员、学科同侪、技术专家），对应「同行研判」 |

### 4.1 物理

| 字段 | 内容 |
|---|---|

| ②法定锚点 | 义教物理（8–9年级）：**物理观念、科学思维、科学探究、科学态度与责任**；高中：**同名四项，但学业质量水平不同**（差异【待核实】） |
| ③专家视角 | 于海波（参与义教物理课标修订）、黄恕伯（初中物理课标修订组核心成员）：初中物理课标解读〔东北师大官网2022-09-12、广州教研院2022-10；详六〕；**主张原文【待核实】** |

| ⑤误区 | 概括中心思想≠细读；发言热烈≠审美创造；禁用理工式认知冲突硬套文学文本 |
| ⑥学段进阶 | 小学：义教四素养；看圈画、换词比较、朗读停顿，内容问题占比相对高（4-5，不写数字）【待核实】。初中：看是否从「写了什么」进到「为什么这样写」。高中：锚点＝高中四素养（表述不同）；看贯穿单元的开放追问、不同立场各自举证 |
| ⑦问题适配 | 人文三级（4-8，表4-8-1四维）：基本问题贯穿单元、开放无标准答案；内容问题有明确答案；核查是否只有内容问题 |
| ⑧议课请谁 | 学科同侪（文本多种解读是否被留出）＋科组带头人／教研员；据3-1「同行研判」 |

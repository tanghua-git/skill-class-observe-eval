# CREATE 观课评课检核表

> 来源：哈士奇聊教学设计《如何观课评课？CREATE观课评课检核表》
> 适用于课堂观察时进行结构化记录和打分。

## 使用说明

听课时对照六个维度逐项观察记录，每项评分 1-5 分（1=未体现，5=典范级）。听课后汇总反思。

---

## 一、Context — 情境与学情分析

**核心关注**：教学设计是否基于真实的学情和认知背景？

| 检核项 | 评分(1-5) | 观察记录 |
|--------|:---------:|----------|
| 教师是否在课前进行了充分的学生洞察（已有知识、经验、兴趣） | | |
| 引入环节是否创设了与学生生活经验相关联的真实情境 | | |
| 情境是否有效激发了学生的内在学习动机 | | |
| 教学设计是否考虑了不同层次学生的差异 | | |

---

## 二、Resources — 资源与学习支架

**核心关注**：提供的学习支持是否有效降低了认知负荷？

| 检核项 | 评分(1-5) | 观察记录 |
|--------|:---------:|----------|
| 教学资源（课件/讲义/工具单）是否辅助学习而非堆砌信息 | | |
| 是否提供了必要的「脚手架」（思维导图/流程表/决策清单等） | | |
| 支架是否能帮助学生跨越最近发展区独立完成任务 | | |
| 多媒体/教具使用是否必要且合理 | | |

---

## 三、Experience — 体验与流程设计

**核心关注**：学习路径是否符合认知规律？

| 检核项 | 评分(1-5) | 观察记录 |
|--------|:---------:|----------|
| 教学流程是否遵循由浅入深、由易到难的逻辑 | | |
| 课堂节奏是否有张有弛，避免单一节奏疲劳 | | |
| 学生在各环节的参与度如何（被动接收 vs 主动探究） | | |
| 学生是否在挑战与技能之间找到了平衡（心流状态） | | |

---

## 四、Aim — 目标与教学对齐

**核心关注**：教学活动是否精准服务于学习目标？

| 检核项 | 评分(1-5) | 观察记录 |
|--------|:---------:|----------|
| 每个提问/讨论/练习是否与核心学习目标高度一致 | | |
| 是否存在表面热闹但与目标无关的冗余环节 | | |
| 教学目标是否清晰可评估（学生知道要学什么、学到什么程度） | | |
| 教学重点、难点是否在课堂中得到有效突破 | | |

---

## 五、Task — 任务与真实性

**核心关注**：学生是否在解决真实问题？

| 检核项 | 评分(1-5) | 观察记录 |
|--------|:---------:|----------|
| 教师设计的任务是记忆复述型还是真实问题解决型 | | |
| 任务是否具有真实背景和复杂情境 | | |
| 学生是否在解决问题的过程中实现了知识向素养的转化 | | |
| 任务难度是否适中（不过于简单也不超出学生能力） | | |

---

## 六、Evaluation — 评价与反馈闭环

**核心关注**：是否有明确的证据表明学习已经发生？

| 检核项 | 评分(1-5) | 观察记录 |
|--------|:---------:|----------|
| 教师是否在教学过程中嵌入了形成性评价 | | |
| 是否根据学生的即时反馈调整了教学策略 | | |
| 评价方式是否多元（不只是提问对错，含观察/讨论/展示等） | | |
| 学生是否获得了及时、具体、建设性的反馈 | | |

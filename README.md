# skill-class-observe-eval 课堂观察评课技能

> 面向中小学教研场景的专业评课技能（ima.copilot / OpenClaw Skill）。基于听课记录、课堂录音纪要或教学录像描述，生成结构化评课报告（Markdown 完全版 + 简版）及**排版规范的专业 Word 文档**（A4 / 深蓝主题 / 斑马纹表格，可直接打印存档）。

## 方法论框架

本技能融合三大方法论：

| 方法论 | 来源 | 在技能中的作用 |
|--------|------|----------------|
| 观课议课 | 陈大伟《观课议课与教师成长》 | 评课总理念：成长至上、以人为本、以学论教、从批评走向建设 |
| CREATE 教学设计模型 | — | 六维检核（情境/资源/体验/目标/任务/评价），1-5 分质性锚定 |
| 深度理解评课框架 | 胡小勇团队《问课：智慧课堂教研指南》第 1 章 | 以思立课：课堂思维观察五证据、深度学习/浅层学习产出区分、"好课三迷思"鉴别 |

**评课的核心主张**：好课的特征不变量是"深度理解"——它需要被设计、被激发、被看见、被证明。评课的全部工作是围绕这四件事取证与建设，警惕"热闹≠深度、讲得多≠学得深、活动多≠思维多"三大好课迷思。

## 功能特性

- **输入预处理**：录音纪要专项清洗（剥离时间戳/语气词、术语还原）、输入质量三级评估与降级策略（不足时输出《观察提问清单》而非硬编报告）
- **四维十点观察分析**：学生学习（核心）/ 教师教学 / 教学凭借 / 教与学的关联，每个观察点均要求现象白描 + 分析评价
- **课堂思维观察五证据**：提问质量、表达逻辑、观点碰撞、迁移应用、反思习惯——"重思维培养"类结论必须落到可观察证据
- **好课三迷思鉴别**：亮点定级前过筛，防止把"气氛活跃/讲得透彻/活动丰富"等表面繁荣误判为教学亮点
- **报告生成**：完全版（Markdown + Word）+ 简版（600-800 字速读版）
- **专业 Word 排版**：A4 纵向、深蓝标题体系、表头深蓝底白字（跨页自动重复）、数据行斑马纹、引用块左竖线+底色、页码域自动更新
- **反例黑名单**：14 条语气/方法论/角色禁区 + 12 项输出质量自检清单，杜绝"这堂课很失败"式评价与常模化打分

## 文件结构

```
skill-class-observe-eval/
├── SKILL.md                              # 技能主文档（流程/模板/禁区/自检）
├── README.md
├── references/
│   ├── create_checklist.md               # CREATE 六维检核表（含评分标准）
│   ├── observe_record_template.md        # 观课议课通用记录表 + 课前会议要点
│   └── thinking_evidence.md              # 《问课》深度理解评课工具包（五证据表/产出区分表/三迷思鉴别/议题工具箱）
└── scripts/
    └── md2docx_report.py                 # Markdown → Word 转换脚本（v2 专业排版）
```

## 快速使用

1. 将整个目录复制到 ima.copilot / OpenClaw 的技能目录（如 `~/.skills/class-observe-eval`）
2. 在对话中说"评课"并粘贴听课记录 / 指定知识库中的听课文档 / 上传课堂录音纪要
3. 技能自动执行：背景确认 → 多维分析 → 三迷思鉴别 → 亮点/生长点挖掘 → 生成完全版 + 简版 + 专业排版 Word

### Word 转换脚本独立使用

```bash
python3 scripts/md2docx_report.py 报告.md 报告.docx
# 依赖：python-docx（pip install python-docx）
```
